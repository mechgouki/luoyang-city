# R11 全城复原母图的坐标与轮廓方法

R11 将已具空间证据的对象和可追摹构件接到同一个绘图母框。母框使用原有图06a的西安1980坐标来源及局部米制投影；在这个框架中，来源图线、刊载平面轮廓和候选尺度片分别保存。统一坐标解决联读与编辑问题，原址精度仍由每一项来源本身决定。

## 1. 母框的定义

稳定标识为 `r11-xian1980-source-local-aeqd`。横坐标向东，纵坐标向北，单位为米；投影严格引用 `tools/prosperity_maps.py::PROJECTION`：

```text
+proj=pipeline
+step +proj=unitconvert +xy_in=deg +xy_out=rad
+step +proj=aeqd +lat_0=34.7333333333 +lon_0=112.6166666667
+a=6378140 +rf=298.257
```

原点取来源坐标中的东经112.6166666667°、北纬34.7333333333°。没有进行西安1980至WGS84的基准转换，也没有新增现场测量。输出使用GeoJSON的几何嵌套格式，但坐标是本地米制绘图坐标，不能作为RFC 7946经纬度数据直接提交地图服务。

`research/prosperity-v1/geographic-evidence.json`中的28项古代来源几何由既有`projected_features()`原样转换。所有折点、折线断段、图符点和既有范围性质保留。现代洛水线与邙山方位标签两项不进入此层。宫城北缘暂闭合的旧显示包络仍计入来源清单，但默认隐藏；其北边不能成为新复原的已证宫墙。

## 2. 局部轮廓与来源概览的接入

### 宫城阊阖门

S37原图及既有描摹位于`research/prosperity-v3/gate-plan.json`。`build_gate_geometry()`先依20米图尺和标北线转换为图内局部米制，共10项：主门基、三条通道可辨中段、两阙可见边、两阙地下虚线及两段连接走向。后六项保持开放线；连接走向没有完整廊宽含义。

局部原点是主门基四角的图面均值。R11暂将其接到06a宫城阊阖门图符，工作朝向取06a阊阖门和太极殿两个图符的方向。这个接法保存原图形状、比例和内部相对位置，尚未验证两个图面原点是否对应同一现场中心。旧P3数据中的`city_overlay_allowed=false`、`registration_verified=false`保持原值；R11另立候选绑定，没有回写旧证据。

S37的20米图尺为81像素，名义换算为0.24691358米/像素。图读门基约45.9×25.4米，表列44.5×24.4米单独保留。比例尺没有为追求表值一致而被反向调整。

### 永宁寺刊载平面

新增来源为杭侃《〈洛阳伽蓝记〉慧嶷故事四论》，《故宫博物院院刊》2025年第11期印页061图二右图，在线PDF第9页。图注指向1996年永宁寺考古报告第7页。本轮取得并阅读的是官方重刊完整图；1996年报告原页尚未独立取得，重刊图注中的书名年代误记另存来源记录。左侧“立塔为寺”模式图未作为实物轮廓输入。

`research/city-plan-r11/yongning-published-plan.json`保存原生图像信息、来源校核、图尺、北针、23项描线及像素量读。内容包括七段分墙线、塔地基与塔座、四侧突出部分、佛殿图示框、南门及西门基址、东门标位、西南角开放边、津阳门大道、坊间路与水沟图线。完整寺院没有被合成一个填满的建筑面；门缺口按图保留，东门标位没有扩大为完整门基，未见轮廓的北门没有补绘。

图中图例明确区分发掘与复原的柱础、地石、础痕。这不等于所有外边界都已被证明是现场发掘实线。输出保留每项`source_legend`和`evidence_status`，统一称刊载平面图示轮廓。佛殿框的几何来自刊载图，不能据它宣称本轮确认了完整佛殿的米制实测边界。

0—50米图尺取157像素，名义换算为0.31847134米/像素；尺端按各±2像素记录量读范围。局部原点取塔座主体外框中心，不包括四侧突出部。图内标北线建立局部北；R11暂将此北向接到母图北，将塔座图示中心接到06a塔符。两个中心的现场对应和外部真北均未独立核验。

新图南门的平均对边图读约45.7×19.0米，长边在图内大体东西向。这补充了旧M06表值45.5×19.1米未标明方向的问题。寺墙按同一尺读得东西约212米、南北约292米，与附表212×301米仍有差异。两轴均保持同一比例；没有分别伸缩以消除约9米的南北差别，也没有用新图强拟合旧06a七段寺墙。

### 奈良2013宫城概览：独立来源对照层

今井晃樹《漢魏洛陽城—北魏宮城西南隅の調査成果》，《奈良文化財研究所紀要2013》印页52图69，题为“北魏宮城の構造と調査地”。这张概览图以图例区分隔壁、版筑与道路，可以补充宫内隔壁走向、夯土图示范围和道路组织，但不能作为详细考古房基平面。

`research/city-plan-r11/palace-2013-published-plan.json`保存原生PDF矢量坐标及其等比规范图框，共24项：九组隔壁线、六块版筑范围、五条道路带和四个调查点。规范图框只将PDF点单位平移并乘以4，方便复用局部图的校准接口，不经过图像生成、透视校正或按另一张图变形。原刊图的0—200米尺和标北线单独保留。黑色调查区标块只保存为点标识；它们的图面大小不变成门基尺寸。灰色“版筑”范围以`published_rammed_earth_extent`等来源角色保存，不称作已知殿身、完整房基或屋顶轮廓。

这组图线以阊阖门／1号门调查标识的图示中心候选接到06a同名门符，原图标北暂与母图北一致。图69中阊阖—太极的图示点距为501.677米，而06a为573.882米，差72.205米。按各自图北进行一次锚定后，图69太极图示参照比06a太极点约东21.7米、南73.2米，平面分离约76.3米。这些都是来源图符和候选绑定之间的差异，不是现场误差或置信范围。两幅来源的图符并非经过确认的共同物理点；本轮保留差异，不以第二个太极点重新缩放整组宫墙与夯土几何。

全部特征均标记`source_plan_id="palace-2013"`、`toggle_group="palace-2013"`和`default_visible=false`。它作为独立宫城来源层显式开启或在专门对照视窗中展示，不静默并入06a墙线。阊阖及永宁寺的33项局部轮廓与这批概览特征分开统计，避免把概化宫城图形合称为新核实建筑基址。

## 4. 可复算的变换

原图像素先转换为图内米制：

```text
x_local = m_per_px × dot(pixel - origin_pixel, east_unit)
y_local = m_per_px × dot(pixel - origin_pixel, north_unit)
```

设`b`为从母图北顺时针量取的候选方向，接入共同母框的矩阵为：

```text
x_master = cos(b) × x_local + sin(b) × y_local + anchor_x
y_master = -sin(b) × x_local + cos(b) × y_local + anchor_y
```

统一比例始终为1。S37使用来源宫轴方向；新永宁图及奈良宫城概览各自的局部北暂与母图北对齐。尺寸片按各自约定生成局部几何，再作同样的刚性变换。投影结果不作重新配准，未知边界不补点，图中缺口不被连接。

`frame-bindings.json`保存七项绑定的源文件、指针、原点定义、锚点、朝向规则、假定及限制。构建结果中的`bindings`进一步保存实际母图锚点、转角、3×3矩阵及原图校准参数，便于重新计算。所有绑定的`verified_shared_controls`均为0，`field_registration_verified`均为false。

## 5. 数据接口与核验

```python
from pathlib import Path
from city_plan_r11_geometry import build_geometry

geometry = build_geometry(Path("/workspace/luoyang-r11"))
# frame / features / bindings / sources / diagnostics
```

每项特征具有稳定`id`、`component_id`、`entity_ids`、`label`、`geometry`、`geometry_role`、`placement_status`、`source_refs`和`limits`。来源引用保存文件、JSONPointer、SHA-256、可读定位语及可用外链。太极殿等没有既有目录身份的构件保持空`entity_ids`，几何构件不强行充当新增历史实体。

三种位置状态应在图例中始终可区分：

- `source_frame_reuse`：原06a同源几何。
- `candidate_source_symbol_attachment`：原局部轮廓向母图的候选绑定。
- `candidate_dimension_template`：有依据长宽的候选尺度片。

源项逐点调用原投影函数，并与原函数返回值作严格相等核查。局部图保持统一尺度和原线段拓扑。构建时还检查特征ID唯一、数值有限、仅有依据的闭合轮廓显式闭合、来源输入未变，以及新增永宁文件是否真实加载。新图缺失时构建结果明确记录缺项，不生成一座替代寺院。

候选坐标保留小数用于复算，显示时宜用约数。图尺量读区间是人工读图扰动范围，不是现场误差或统计置信区间。共同绘图坐标、局部尺度的可复算性与历史定位的可靠程度分别呈现，读者才能知道哪些关系已经较前版增强，哪些部分仍待下一份原始证据。
