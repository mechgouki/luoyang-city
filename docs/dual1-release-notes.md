# 双图并行第一批 / 文献工作图v2.10 / 入口v3.1-alpha.1

## 用户目的和实施范围
原文献图继续深化，新地形图独立建设。旧版封存，不以地形新图替代文献研究，不将现代DSM当北魏地面。

本批在同一母图上替换10组建筑、桥梁、学校的图形内容与作用范围说明，并由该母图裁出R07、R04、R10三个重点阅读图。地点锚点保持原示意位置；这是构件/类型/时层表达深化，不宣称发现10处新古址。原v2.4母图、37页图册、v2.5—v2.9研究和v3.0地形产物均保留。

## 原图具体推进
- 永宁寺分塔与塔北佛殿，不补院墙、僧房开间、实际间距或已证中轴。
- 太尉、司徒、宫前国子学改用类型建筑图符；路侧仍为工作解释，未合并太尉/太府或两处学校。
- 景乐保留御道〈东〉校补；停戏不是寺毁。
- 建春门石桥明确527雨毁属于盛时综合区间内变化。间断桥面是事件提示，不是547残桥实测。
- 东石桥保留南北通行，不接收建春桥毁事件。两桥名称同体问题另层。
- 龙华寺保持阳渠南关系，不补渠宽或寺界。
- 景明塔的完成年未证；虚线不是永久在建。三池、水功仍保留构成目录，未擅放院内。
- 城南汉国子学堂与石经分别处理；546迁石经不等于学堂消失。

所有改图有M01—M10登记，保留对应实体、旧画法、新画法、E/N/T证据编号及原引。新图符的矩形、屋顶纹理和重复线只是类型表达，不能统计成古代房间或占地。

## 新地形样板
使用已核的Copernicus真实现代DSM产物。61×61个30m网格窗口计算局部起伏，结合现代显示坡度，分起伏较缓、过渡、起伏较强三类；邻域不完整处不分类。阈值只是探索性读图规则，不是经地貌调查证明的台地、河漫滩、稳定区、城市填筑区或古河道。现代地表受到建筑和植被影响，平滑不意味着去除它们。

原始高程与山影继续可切换。所有10项古代经纬度为null，地形图上没有古代建筑定位点。建筑群放在明确分框、无牵引线的文献插图里，点击可回到原图同一对象。因此本批交付的是独立地形解释及建筑群表达样板，而不是完成古城整体地理配准。

## 网页、下载与保留
首页主地图实际载入新的文献母图，而不是只更换版本标签。新入口`dual-map.html`可在新版、原版、地形之间切换，选择三片区，缩放、拖动、点击构件、查看依据、复制深链接。旧专题保留。页面和下载有Copernicus完整来源与免责声明。

完整工作包包括新版母图、三个分图、地形分类GeoTIFF与PNG、独立样板SVG、改图CSV、JSON、HTML报告及生成程序。离线报告可直接打开；交互工作台需HTTP服务。返回旧证据模块的链接需完整站点或正式网站。

## 构建与检查
在原v3.0链之后执行`python tools/dual_release.py`。研究算法由`tools/dual_batch1.py`负责，包装与来源声明由`tools/dual_release.py`负责。

新增16项语义/数据测试与真实HTTP浏览器测试；保留原有全部检查。当前本地HTTP导航受环境策略限制，不能以离线渲染冒称线上验收。实际PR、部署与生产验收结果写入Issue #15和PR。

关闭实施任务不等于历史配准、古河道或全部院落细节已完成。敏感带、稳定地貌、古代建筑经纬度均仍需独立证据，未用主观选图替代。
