## 主图的制作方法与限制

整幅生成多次未能落实楼层数或原塔脚位置，这些试绘没有获准成为首页图。最终制作将图像生成得到的无塔庭院背景，与按V6原生参数绘制的独立投影塔层组合。背景位图的修改由图像工具完成；塔层由SVG原生构件绘制，网页图片是该原生场景的正常渲染输出。

塔层沿用九层墙身、九道主檐、八道上层外廊和十一重金盘，楼面标高、收分、台基尺寸、出檐和屋顶高度来自V6参数文件。柱、门窗、斗栱笔画用于表达造型，不能作为承重截面或实际节点尺寸。

塔脚依据V12图片内的视觉落点摆放。投影系数只是本画面的构图选择，**不是历史相机标定、古代地理控制点或全城统一米制测量**。其与R12/V14使用的frozen H是不同对象，后者原文件保持不变：
