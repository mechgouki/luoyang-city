## 本批地形结论与下一步

B4仅解决扫描像素到原图印刷网格的内部校准。B5已核读14张原图边栏裁片，并追到原馆固定版本FGDC XML：哈佛在2005年2月为整套影像统一赋予WGS_1984。馆方同时记录AMS未随该系列公布关联水平基准。这是后期数字产品的工作定义，原纸图水平基准继续为未知。

哈佛每幅4组角点附近的印刷UTM坐标与B4每幅8拟合、5同图留出分开登记；两者影像和控制方案不同，RMS不能互换或据此排名地面精度。当前具名稳定地物0、获准地面控制点0；3类待查方向和2类排除规则只是审核队列。

接下来按以下顺序推进：

1. 继续追查原始编图或大地测量依据；International Spheroid只是椭球说明。资料不足时继续保留未知，不把哈佛数字化WGS84继承给纸图。
2. 按已建立的审核队列寻找具名稳定地物，分别标明图上身份、近现代变化、现代对应和出处；不能用文献图像素、文字中心或活动河岸当控制点。
3. 将拟合点与独立地面检查点分开，报告系统偏移、局部残差及图幅边缘表现；B4同图留出点不能替代此步。
4. 通过上述检查后，单列有年代的近代水系参照，再与古代文本的桥、渠、流向和时层逐条比较。不能把近代河岸直接赋给北魏。

验收产物应包括基准论证、点位出处、残差和例外清单、并排对照图。只有证据允许才作地理叠加。
