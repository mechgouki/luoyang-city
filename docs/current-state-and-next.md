## 本批文献图：B6 城东南门内外

EI01—EI16核对东阳、青／清阳、开阳门内的寺、署、池与园；EO01—EO18核对门外里属、市场、冢旁关系及宅寺年代。四个电子卷册仍来自《洛阳伽蓝记》一个古籍来源家族，现代校注和注引不冒充独立原书互证。

同一母图更新17个已有地点与3座城门的类型图符，不移动锚点。典虞曹使用官署型，苏秦冢标传称，洛阳小市使用市场型，城东建中在工作层保留杨氏宅。愿会、宜寿、光明、胡统及归觉不拆出新的定位节点。

需要持续保留的判断：

- 青／清异写须按具体条文登记。周、范门序均作青阳；范修梵条保留清阳，不能简写成“周青、范清”。
- 正始寺道南沿用周校，范电子正文仍作西，二者并非共同证明道南。典虞与正始仅同属敬义里，既有画面东侧位置不是正文东邻关系。
- 愿会在昭仪池西南；宜寿“寺南”保留回指层，光明承宅改寺关系。昭仪池与翟泉分开；石崇家池身份标为赵逸所说。
- 嵩明在修梵西不能自动继承御道北；景林寺西之园不能自动继承御道西。小市、殖货也不无条件继承孝义里的路侧。
- 孝义里西北角直接修饰传称苏秦冢；宝明只得冢旁。宝明的前期年代依赖两条同名记载的候选联接，冢旁条本身没有独立前528纪年。
- 平等寺本体与532始造塔分时，毕功533／534分列。秦太上君五层塔没有独立完工年。归觉永安宅改寺属于河阴之后，城东建中又晚于531事件。
- 愿会“五重”是神桑，光明晋代日期属像铭，景林普泰初属任官叙述。均不能移作全寺营建或塔层依据。
