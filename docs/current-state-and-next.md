## 下一批地形：先查水平基准，再做跨年代地物检查

B4仅解决扫描像素到原图印刷网格的内部校准。接下来按以下顺序推进：

1. 查图系列、边栏和编图说明中的完整水平基准；International Spheroid只是椭球说明。资料不足时继续保留未知，不预设WGS84。
2. 建立候选稳定地物表，分别标明图上身份、近现代变化、现代对应和来源；不能用文献图像素当控制点。
3. 将拟合点与独立地面检查点分开，报告系统偏移、局部残差及图幅边缘表现；B4同图留出点不能替代此步。
4. 通过上述检查后，单列有年代的近代水系参照，再与古代文本的桥、渠、流向和时层逐条比较。不能把近代河岸直接赋给北魏。

验收产物应包括基准论证、点位出处、残差和例外清单、并排对照图。只有证据允许才作地理叠加。
