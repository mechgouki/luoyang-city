# B7：外邦图单幅目录与来源连续性审核

本批在 B6 已核的 L531 实物边栏基础上，向日本十万分一图与其中国底图继续追查。新增成果是三个可逐项复查的国立国会图书馆（NDL）单幅目录记录，以及各自的摄影、测量、制版、出版和底图年代。**本批没有取得这三幅历史地图影像，也没有确认任何一幅就是 L500 实际采用的源图。**

研究基线：`9d0580332d635beb1d68963ae6c032598c2ff515`。核读日期：2026-11-13。机器可读记录为 `research/dual-b7/source-continuity.json`。

## 1. 为什么这一步有实质增量

B6 的原图边栏已经把两个不同问题分开：L500 西幅 NI49-7 列有日本 North China 十万分一图（1942—44）；东幅 NI49-8 列 I-49-K/L（1945），没有列日本图源。B6 所见 Princeton L531 图为 1946 印本，边栏记 1945 编图，并列中国五万分一图、Central Land Survey、1931—38。因此，下一步需要逐幅查馆号和制作依据，不能只按系列名或一个共同年份接上来源链。[B6 原图边栏及裁片](../research/dual-b6/ground-review.json)；[B5 L500 编图来源栏](../research/dual-b5/historical-datum.json)。

NDL 的外邦图索引提供了馆号入口。本批将索引格与单件目录交叉核对，实际读取三条官方目录的“シリーズタイトル”“出版年月日等”“一般注記”。索引是现代馆藏检索工具，没有作为历史实图或坐标来源使用。[NDL 外邦图说明](https://ndlsearch.ndl.go.jp/rnavi/maps/post_307)；[十万分一图馆藏索引，第 1 页](https://ndlsearch.ndl.go.jp/file/rnavi/maps/post_307/g045.pdf)。

### 2.1 郑州：1942 年摄影与测量，有具体候选但没有实际用图证明

官方题名为“鄭州 河南省中牟縣・鄭縣・新鄭縣・榮陽縣・密縣・榮澤縣”；系列为“北支那十万分一圖 ; 開封 11號”；馆号 **YG821-2507**，书目 ID **000008299342**。北支那方面軍參謀部測量班为制作／出版机构，比例尺 1:100000，纸本一张、39×55 cm，出版地与年分别以 **[南京]、[1942]** 著录。[官方单件目录](https://ndlsearch.ndl.go.jp/books/R100000002-I000008299342)。

一般注记：

> 昭和17年11月測量 (昭和17年8月撮影) 要圖 (空中寫眞測量)

这条注记明确区分 1942 年 8 月摄影、同年 11 月测量，并把图标为要图／航空摄影测量。证据类型仍是**图书馆目录一般注记**，不能写成“本次从图边直接读出”。[同一目录：一般注記](https://ndlsearch.ndl.go.jp/books/R100000002-I000008299342)。

时期与机构和西幅所引日图相容，故保留为目录候选。但是，目录题名及索引指向郑州及周边县，不能仅按年份将其放入西幅 NI49-7 的实际来源链；东幅 NI49-8 也不能被补写为采用日图。尚缺本幅原图边界、印次与 AMS 逐幅引用记录。因此 `period_matches_l500_west_citation=true`，而 `actual_l500_source_match=false`。

### 2.2 偃师：1934 制版并不等于当年新测

馆号 **YG821-2519**，书目 ID **000008299355**；系列“北支那十万分一圖 ; 西9行南1段 開封 21號”；题名列孟县、洛阳、偃师、温县、孟津、巩县。目录载 1934 年 4 月出版，1:100000，纸本一张、46×58 cm。[官方单件目录](https://ndlsearch.ndl.go.jp/books/R100000002-I000008299355)。

一般注记：

> 昭和9年製版 (中華民國15年國民革命軍總司令部參謀處製河南省十万分一圖)

据此可以分别记录 **1934 制版**与 **1926 年、國民革命軍總司令部參謀處、河南省十万分一底图**。目录未给出新摄影或新测量日期，不能把制版年替换成实测年。[同一目录：一般注記](https://ndlsearch.ndl.go.jp/books/R100000002-I000008299355)。

本次目录中的 1934 版次早于 L500 所引 1942—44 时段，因此排除将这条现有记录直接视为目标印本。这个决定不排除尚未找到的后续修订或翻印本，也不否定偃师与研究区域的地域相关性。

### 2.3 汜水：1931 年中国五万分一底图成为可继续追查的具体线索

馆号 **YG821-2516**，书目 ID **000008299352**；系列“北支那十万分一圖 ; 西9行南1段 開封 16號”；题名列河阴、温县、巩县、荣阳、武陟、沁阳、汜水、偃师。目录载 1935 年 1 月出版，1:100000，纸本一张、47×58 cm。[官方单件目录](https://ndlsearch.ndl.go.jp/books/R100000002-I000008299352)。

一般注记：

> 昭和9年製版 (中華民國20年參謀本部陸地測量總局製河南省五万分一圖)

这提供了 **1931 底图 → 1934 制版 → 1935.1 出版**三个不同层次，并给出底图机构“參謀本部陸地測量總局”及 1:50000 比例尺。[同一目录：一般注記](https://ndlsearch.ndl.go.jp/books/R100000002-I000008299352)。

1931 与 1:50000 同 L531 边栏的 1931—38、五万分一相容，但这种相容没有证明同一幅地图、同一机构实现或同一引用关系。这里**不把中文机构名直接等同于 L531 的 Central Land Survey**。仍须查该底图的图幅号、印次及原件，再与 AMS 编图清单对应。本批 `actual_l531_source_match=false`。

## 3. 可复核的记录与获取限制

三幅单件目录均以 HTTPS 获取官方 NDL Search HTML，读取可见书志字段。机器可读记录保存请求 URL、书目 ID、馆号、取证位置、获取日期与本次响应字节 SHA-256。该哈希用于识别本次取得的响应，**不是对动态网站内容永远不变的保证**。检索工具的 NDL 单件／API 页面预览返回错误，不能用它的错误结果代表目录不存在；本次成功读取来自官方 HTML 响应。

| 馆号 | 官方 API 入口 | 引用位置 |
|---|---|---|
| YG821-2507 | [NDL OpenSearch](https://ndlsearch.ndl.go.jp/api/opensearch?any=YG821-2507&cnt=1) | 出版年月日等；一般注記；シリーズタイトル |
| YG821-2519 | [NDL OpenSearch](https://ndlsearch.ndl.go.jp/api/opensearch?any=YG821-2519&cnt=1) | 同上 |

API URL 为可复查入口，书志正文的证据及响应哈希以 JSON 的 `retrieval_method` 与 `response_sha256` 为准。本批没有把未读取的 API 字段标作已核证据。

没有下载这三幅历史原图，也没有新制作原图裁片；`source_assets=[]`，每条记录 `raw_scan_crop_xyxy=null`。现代馆藏索引只用来查馆号与相对地域。本次不复制整张索引，不提取索引坐标，不用示意图冒充历史扫描。

## 4. 交付表达与审核门槛

`edition-summary.svg` 将五种日期放入对照表，保留郑州 `[1942]` 方括号，并把“目录未记”与“未发生”分开。`continuity-summary.svg` 仅连接各自一般注记明说的制作关系；实际 L500／L531 用图关系放在独立审核栏，不绘制已证实的连线。两板均为 2200×1560，供 B7 总图册统一排版。

网页提供三幅记录选择、时期匹配与早期版次筛选、年代表／来源关系切换、来源详情展开，以及可恢复的 `record/filter/view/open` 深链接。构建只读已审研究 JSON，不在 CI 重新抓取图书馆网站。`metadata.json` 从站点 `build-info.json` 继承 `source_commit`，发布身份和研究基线分别记录。

继续推进需要：

1. 依三个 YG821 馆号取得原件或许可影像，核图幅边界、印次、摄影与测量说明。
2. 分别查偃师 1926 十万分一、汜水 1931 五万分一底图的图幅表和实际图号，不能只追宽泛系列名。
3. 查 AMS 编图清单、修订记录或逐幅引证，证明真正用图关系。年代、尺度与地域相容只是筛选条件。
4. 完整水平基准与跨年代稳定物理点另立审核；原图索引、地名文字和版次相容均不自动变成地面控制点。

本批结果保持：**原纸图完整水平基准未知；未赋地理 CRS；没有 WGS84 配准；没有地面精度判断；获准地面控制点 0；新增古址经纬度 0；新增古河道 0；现代 DSM 未修改。**
