## 对V13候选图的实际约束

以下为R7已核判断的继续执行，本次访问不使其证据等级上升：

1. **宫前御道保留陆路。** 夹路支水只在路旁提示，不画成贯穿中轴的单一明渠；支水接口和渠宽仍缺依据。
2. **城东水线保留分期。** 路北调查渠迹与路南研究解释不能在全景中同时表现为两条同期已测河岸；门下汉晋暗渠不补接到北魏桥渠。
3. **三桥不排成同轴桥列。** 东石桥的南北桥向、第一桥的527年事件及七里桥的不同里程参照仍各自保存。画幅不能清楚表达时，降低桥头细节，不补精确位置。
4. **未知路端继续留缺。** 新全景的背景补景不能反过来生成道路实测线、郭门或古岸坐标。
