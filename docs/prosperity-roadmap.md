# 盛时洛阳：四阶段实施路线

用户确认日期：2026-11-14。接续已发布 H1，先完成盛时，毁后场景后置。

## 最终成果与顺序

1. **完善盛时文献平面图。** 时间沿用516—528年河阴事件前的文献综合时层。核对全部既有地点、建筑构件、方位、距离与引用类别；区分古籍正文、节录、校注和项目解释。已有339实体的ID及封存几何保留，新修订有独立工作层与更正记录。
2. **建立历史地形与定位依据。** 区分现代地表、近现代地图、机构公布的遗址范围及北魏文献地形。为每个可用位置记录来源、时期、坐标含义、尺度与误差；先建立城市核心与空间骨架，再逐区补足。历史地图配准与古代地面复原是不同任务。
3. **形成盛时城市分布复原图。** 将可核验位置、范围与文献关系放在共同地理空间中。原图上已绘范围、候选范围、相对关系和未定位对象分开表达。文献画布坐标不直接转换成经纬度；一处登记参考点不能充当所有古代建筑的锚点。
4. **根据布局深化城市全景。** 从同一套经过记录的布局生成鸟瞰或立体体量。已知布局与示意高度分别注明；画面中的新增细节不得反过来充当历史证据。最终美术效果服从城市关系与空间依据。

## 交付与完成口径

每阶段交付可用地图、对象证据、数据下载和具体变更说明，并依AGENTS完成正式站验收。第一版可保留研究未定项，但必须明确覆盖范围、位置等级和仍然不能推出的结论；不得用第一版工程上线声称全城每栋建筑已经复原。

盛时文献图与地理分布图共用对象ID。地理参照来源若描述现代遗址或多朝代叠压，必须保存其自身时层，不能无条件下传为516—528年每一年的现状。

## 本轮工作分配

- 文献线：183条历批证据的分类与可复核引文核验；236处字面约束引用的候选链接与非实体用语辨析；形成有实际图面作用的决定。
- 地理线：先取得足以支持城市核心的机构地图与位置依据，同时继续历史图源链研究；只登记实际核读到的资料。
- 产品线：新增盛时复原入口，提供文献平面、地形与布局，以及有相同布局依据时的鸟瞰；保留H1和B1—B8全部旧入口。
- 发布线：实现、构建、浏览器与线上资源验收通过后自动更新网站，保存长期验收证据。
