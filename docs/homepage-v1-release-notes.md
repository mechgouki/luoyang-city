# H1：从城市全景走进洛阳文献地图

日期：2026-11-14。界面版本：`homepage-v1`。研究基线：B8；几何封存基线：v2.4。

## 为什么更新

原首页在互动地图之前排列了各批研究与版本入口，首次访问者难以迅速理解网站可以探索什么。用户确认“城市画面 → 历史问题 → 互动地图 → 研究资料”的顺序，并要求首页主图更宏伟、减少明显的AI质感。

## 本次变化

- 用宽幅北魏洛阳城市概念图作为首页首屏，保留城市全景与木塔的尺度关系，采用自然日光和沉稳材质。图片旁明确写明“研究性复原示意”。
- 提供“开始探索”入口，直接到达既有互动地图，继续使用地点检索、分区、缩放、证据侧栏与图层。
- 增加三个问题入口，每一个都连接已有的地图或证据案例。
- 将各批研究入口与方法说明放到互动地图后。专题深链接直接进入原来内容；`#home`可返回首页。
- 为主图提供两档WebP资源，原始图像1672×941，较小图像960×540；图片构图不因压缩或缩放重新生成。加载资源使用内容指纹。
- 在既有发布流水线末尾运行`tools/homepage_v1.py`，并在本地与正式站验收中增加首页浏览器流程。

## 图片性质与来源

主图是2026-11-14按用户反馈重新生成的首页概念图，使用内置图像生成能力。场景提示围绕北魏洛阳516—528年盛时综合语境，以远景都城、连续街坊、长街、宫城和一座主木塔表现规模；明确要求自然日光、灰瓦土墙木构、合理透视及微小人物尺度，减少浓雾、金色泛光、塑料材质和夸张建筑。它不是古代照片、考古测绘成果或逐栋建筑学复原。

图中院落形状、屋顶样式、人物车马、远景轮廓及具体空间距离均不作为项目新增证据。文本推断与原有文献地图继续独立表达，新增古址坐标、古河道及研究确证数量均为0。
