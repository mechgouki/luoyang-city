# v2.9 同址时层对照（首批） / 网站0.6.0

## 本批目的
将盛时叙述与后续变化放在同一地点阅读，而不是把全城底图整体染成547年废墟。继承v2.4示意几何、v2.5证据、v2.6空间模型、v2.7事件作用范围、v2.8默认地图整合。新模块不修改旧研究JSON和封存图册。

## 交付
12处地点档案、25条分作用对象的时层记录；11处沿用非群组锚点。城内建中只在名录，不新增点；石经通过关联的城南汉国子学堂阅读，不合并宫前国子学。两处建中保留不同实体。

默认首页提供显著入口；`#compare?site=D29-01&year=547` 为同址对照，双图同步缩放、拖动、点选。`v2.9.html` 为独立新版入口；v2.8.html继续保存旧版阅读方式。代码、样式和新数据使用内容指纹。

日期分确年、年号区间、同条异记、只有下限、叙述现在、无年。异记528/531不变成连续区间；下限不定为确年；至今不自动等于547；过去事件不自动永久延续。平等塔533毕功不移给景明塔；景乐此戏遂隐不记为寺毁；瑶光入寺侵扰不改为火灾。

## 研究边界
两张图共享背景示意地理而非两个历史时点的已证建筑清单。首批12处为片段核查，339对象账本中另外327处未进入本批；不是全库年代考证完成。12处547年完整存废均未据现有片段确证。短引、卷条和电子文本链接可复核，但没有声称完成古刻书影逐叶校勘。年代换算与上下文定年须与原文区分。
