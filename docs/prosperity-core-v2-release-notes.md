## 院界校核带来的判断

对P1原三面寺墙在同一IAG1975椭球局部投影中复算，来源图东西墙的共同正交间距约264.9m，表列院宽为212m。两者相差约52.9m。固定212×301m框贴合南墙后，诊断院心几乎重合于塔符中心；原件中完整院内复原参照图却显示塔偏院心南侧。

本版把两组尺寸画成**独立同尺度比较**，保存未采用拟合的数值、原线段分组、残差和图内关系复核。城市图中的原三面墙保持原几何，未增加北墙。此差异不说明真实古院宽就是264.9m，也不是地面精度测定；P1的100m工作展示设置不能作为接纳拟合的阈值。

## 从图版进入局部构成

实际核读原件PDF1962、1965、1966的小幅内嵌图与既有《洛阳伽蓝记》电子正文，形成3个场景、27个部件、30条关系，依据9条图版观察和7条古文短引。

- **阊阖门区**：主门基内三通道、两阙、四院和两侧基址连接。四院用虚边阅读区；不把基址连接都称为有顶廊。
- **永宁寺院**：塔北佛殿、四门类型差异，僧房楼观为非定位目录。北门“不施屋”；南门“通三閣道／通三道”不能直接定出三个地面通道。
- **永宁塔基**：中央土坯塔心、环绕构造证据与四向慢道。未补柱础数量、整齐柱网、完整环廊或坡道尺寸；破坏沟不转成盛时古渠。

局部图使用独立的无比例编辑画布。节点真实坐标、未知距离与历史高度保持空值；文献关系不被显示间距替代。精确局部描摹和城市定位配准尚未完成。详见[局部结构与出处](prosperity-core-relations.md)。
