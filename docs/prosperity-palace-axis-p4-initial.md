# P4 首批：宫城中轴证据序列（相对关系，尚非宫城实测总平面）

本批承接 P3 的阊阖门原件像素量读，新增四节点与三条顺序关系，数据位于 research/prosperity-v4/axis-sequence.json；没有新增其他门的单体测点、古址经纬度、院界和建筑高度。

## 所见资料与各自的限制

1. UNESCO 1442.pdf 文件第1962页附图：阊阖门原件，可供本图门基、通道、双阙和比例尺量读；不能据此直接定位止车门、端门、太极殿。
2. 钱国祥2018《汉魏洛阳故城居中宫城制度考》：2001—2002年阊阖门发掘；2007—2010年二、三号宫门发掘；三门沿南北轴排列，太极殿位于其北。
3. 钱国祥2019《汉魏洛阳城城门与宫院门的考察研究》（中国考古网账号转载）：将二、三号宫门解释为文献中的止车门、端门。这是有出处的身份判断，不是本站重新取得的田野实测坐标。

原件：https://whc.unesco.org/uploads/nominations/1442.pdf#page=1962
研究2018：https://www.nopss.gov.cn/n1/2018/0704/c373410-30125781.html
研究2019：https://k.sina.cn/article_2145932192_7fe853a001900gcbp.html

## 本轮可编码的最小关系

从南向北：阊阖门 → 二号宫门（研究者对应止车门）→ 三号宫门（研究者对应端门）→ 太极殿。

只编码三条南北相邻关系和出处。节点间距只是图面排版；各期营建、墙垣、道路、北向基准及局部到城市坐标的变换均未核定。文献给出的序列不等于516—528年某一日已证实的完整建筑群。

## 下一步必须补的证据

- 取得二号、三号门及太极殿带比例尺的原发掘平面，记录原图来源和独立可读构件。
- 取得门殿共同控制点、扫描畸变信息、外部方位基准；当前共同控制仍为零。
- 区分曹魏、北魏和晚期叠压修复的建筑形制，检查北魏盛时断面对应范围。
- 以原始资料验证门殿间的道路和院界，不用关系箭头代替实测院墙。
