# 盛时洛阳 P4.3 — 太极殿宫院南北尺度异记与真实院界

本批承接 P4.2 的两套总院尺寸，将2022年公开大众介绍中 **320×370m** 单列为第三种待核口径，**不**改写旧 P4.2 的 A／B 数据、分期模型、院落图、首页暂用全景及任何历史实体坐标。

## 研究结论（截至2026-11-17）

| 方案 | 东西约数 | 南北约数 | 发表层与证据等级 |
| --- | ---: | ---: | --- |
| A | 340m | 310m | 2015考古成果／2017钱国祥讲座；同一团队来源链 |
| B | 320m | 370m | 2022大众游览介绍；待回查直接出处，不是新增考古实测 |
| C | 320m | 380m | 2023政务考古综述；需核其实际使用的院界图和时期 |

三案只能对**报告数字**比较，不能据此选定真实宫墙。相同显示米制的三幅虚线矩形是三个**独立的尺寸片**：矩形不共享南墙、北墙、中心或坐标原点；无现场控制，不允许叠到现代地图。B相对A东西−20m、南北+60m；C相对A东西−20m、南北+70m；C相对B南北+10m。数字差不自动等于测量误差或院墙位移。

## 已取得的其他约束及限制

- 2017年度宫院发掘资料报告东北角局部院址东西约96m、南北残27m，夹道宽约4.7m；**同篇明确称东围廊东侧是整宫院东墙，并报告已确认宫院东界、北界及东北角**。因此这些边界不是“从未发现”，但本项目尚未取得可逐点量读的完整原版实测平面、共同测点和分期控制，不能把报道写成已完成地理配准；残长亦非完整院深。
- 建筑史论文另提整体宫院宽320m和东西堂关系；需回到论文所引原测绘图核清是基址、院墙还是研究示意，不能按二次引用数量投票。
- P4.1的三号宫门到太极殿**200m／300m**是另一组**量距端点争议**。本批绝不用310／370／380m倒推、替换或消除该问题。
- 目前**完整总院实测原图未独立取得**，南北测线、边界时相、现场共同控制点、古代地面、上部屋顶高度均未核定。零新增绝对坐标，不绘地理定位院墙。
- P4.2 的魏晋／北魏／北周叠压依然各自保留；盛时516—528属于研究综合时层，非单一考古层位即时快照。

## 研究下一步

1. 取得太极殿宫院正式发掘总平面及原版图号、扫描分辨率、图内比例尺、院墙线标注和区域坐标。
2. 确认三案所称“宫院”是否同一对象、测量方向和时相；逐一登记北墙／南墙以及三号宫门的关系和量距端点。
3. 以2017年的东界、东北院角与4.7m夹道为局部控制约束，与独立完整院图交叉核实，而不是用面积比反推出未知院界。
4. 若获取共同控制点，再建立独立局部配准与误差审计链，届时才能升级到全城布局；否则继续发布“不定位”的审查图。
