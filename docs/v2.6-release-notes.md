# v2.6：R07 可检验空间复原 / 网站 0.3.0

## 完成的研究目的
从手工证据关系图推进到有明确前提、可计算检验、可追溯反例的同参照空间方案。v2.4 底图仍封存；v2.5 的18张卡继续作为文本与校读入口。本版本不宣称恢复唯一古城平面。

## 数据与算法
482条原关系逐条保留 original、主体、目标解析状态、出处、原单位与时间审阅状态。原161条target_id中160条能找到对象；原321条target中85条本来也是ID，故有效既有ID引用总数245。另198条单名匹配、2条去限定语候选、13条复合表达、24条未解析。名称匹配不裁决历史同体；city_jinyang 的断引用未被擅自补造。

18张证据卡拆为69条原子记录：34条文字方向投影、4条城内外记载、23条明确额外前提、8条不送入几何的注记。引文和转引不是独立票数。全库482条索引不自动送入求解器；本批只审定R07这组原子判断。

求解器只支持严格x/y偏序、显式身份/时相/参照等价及城内外归属。提供每个相容情形的完整秩赋值证书（含未画出的提及节点），每项查询的充分支持集，以及两个庙社的子集极小冲突集。极小不等于基数最小，不声称穷尽所有冲突。

16种情形包含8组路侧/校补开关、3次来源组删减、同体/同时/同城界的全合并与逐个放松、太府与太尉试合并。产生13张同参照、同显示范围的可行例；它们不是13套独立证据支持的历史复原。

## 可以得出的条件性结论
1. 关闭西侧序列继承后，太尉府道西和道东各有可行例；寺东不能单独推出道东。弱模型也未自动排除点恰在道路参照线上。
2. 仅撤去景乐〈东〉补字，但保留司徒道东继承时，依寺西司徒仍可推出景乐道东。两项相关前提都关闭后才未定。这个推导不能当作独立版本证据。
3. 九级与司州的省略/增列可以形成相容偏序；太府与太尉合并和不合并均相容，空间关系不足以判定官名身份。
4. 城内工作对应成立时，门外/城内庙社须同时合并对象、时相和城界参照才形成此类冲突。放松任一层只消除逻辑冲突，不证明迁建、不同时或两座同期建筑。

候选图的每个节点可直接点击回查当前启用与未启用的判断，避免只看图而不知道成立条件。交互命中点从新生成SVG提取，不读取旧底图坐标。

## 显示与边界
`#model?case=s011` 可切换同一约束集的太尉路侧例；`#model?case=s100` 比较景乐路侧；`#model?case=ritual111` 查看冲突；`tab=atoms|relations|sensitivity` 查逐条判断、全部关系或删源矩阵。

候选图未读入v2.4像素。道路直线、宫门北置/对中、邻处近置、未连边先后、分数坐标及标签摆放仅为显示，每条已启用方向另有计算验算。模型不包含真实院界、道路宽度、建筑互不相交、欧氏里程或水道形状。正比例缩放保持所有偏序，所以不输出有限米制范围或概率。
