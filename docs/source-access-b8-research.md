# B8：原图获取、底图接合表与单点连续性调查

本批最具体的新发现是：中央研究院维护的《北京图书馆舆图要录》检索系统中，**目录 4798 把 1931 年河南五万分一地形图著录为 263 幅，并明确记有“接合表1張”**。这给下一步查找汜水所据中国底图的具体图号提供了一个可指名获取的对象。另一个新条目 4788 将 1926 年河南十万分一图落实为 185 幅的目录集合，并记其中少量图幅由河南陆军测量局绘制。[CCTS 4798](https://ccts.sinica.edu.tw/catalog/detail.php?num=4798)；[CCTS 4788](https://ccts.sinica.edu.tw/catalog/detail.php?num=4788)。

**这些是新核实的系列目录和获取目标；本批没有取得目标三幅日图或1931接合表的影像，没有取得其对应中国底图的历史单幅图号。** 目录号 4788／4798 不能当作历史地图图号，也不能据机构、年份和比例尺相容认定 AMS 确实采用了同一单幅。

另有一条待核的非机构线索：[2019年第三方文章](https://sjm460405.blogspot.com/2019/03/blog-post_12.html)的图6文字题注提到1942年《北支那十萬分一開封11號》郑州图。本批只读取文章文字，没有下载或目读该图，也未核完整图边、原件来历和图像权利；因此将其保留在 JSON 的 `deferred_leads`，没有计入已取得原图或确证数字本。后续应先核出处、完整性与合法获取方式，再决定是否可作为证据。

下次查件可直接使用馆号、完整题名和目录版年，并优先说明研究需要：图幅编号及其全部前缀、边框、版记、编图／测量／摄影说明。尚未获得影像时，不预填像素框或地理控制点。

## 4. 候选地物：历史11号桥墩的连续存续假设不能成立

郑州桥工段供稿、发表于2021-12-22的《郑铁传承》文章，将1958年洪灾落到一个具体编号构件：原文记11号桥墩严重冲刷后倒塌，相连第10、第11孔钢梁落水，后来经抢修恢复通车。文末明确“素材来源：郑州桥工段”。[公开原文，1958洪水段及文末来源](https://www.thepaper.cn/newsDetail_forward_15959525)。

因此，本批新增的是一个**具名构件否决记录**：不能把历史11号墩默认为原位连续存续的测量点。抢修后恢复交通只证明功能恢复，不能证明同一基础、同一墩位或同一测量部位没有改变。这比B6整桥多次改建的概括排除更具体，却仍不产生可配准的点。

证据强度也要限定：这篇材料是养护部门供稿的回顾史述，不是1958年原始观测手簿、抢修竣工图或现代工程测量。原始编号如何对应现存构件仍未知；本批也没有在AMS整桥线符号中唯一识别一个11号墩位置。下一步需原始墩号图、抢修重建记录与现代测量来核具体构件身份。记录中的坐标、像素锚点均为 `null`，获准控制状态为 `false`。
