# R5.1 盛时洛阳城市全景

[打开全景](https://mechgouki.github.io/luoyang-city/prosperity-city-panorama.html) · [宫寺体量](https://mechgouki.github.io/luoyang-city/prosperity-city-panorama.html#core) · [全城体量](https://mechgouki.github.io/luoyang-city/prosperity-city-panorama.html#city)

自城南向北，永宁寺居御道西，宫前阊阖门与太极殿沿纵向视线展开。画面采用 R4 图06a顶点投影出的宫寺视角为底稿。建筑位置、二维画面取读与高度等示意参数均可下载。专题供审看，首页继续使用此前批准的 H2/v9 原图。

## 源图与同视角对照

- 以 R4 的 30 项来源要素为底，28 项进入两幅体量图。另两项是现代洛水与邙山标注，留在 R4 现代图层。外郭是相关遗存概略范围，宫城候选面无边线，内城地下残线和八条道路保持断段。全城平行投影以外郭为范围。核心透视图从南向北，南部按画幅裁切。
- 体量沿用 P4.5.1 的四项建筑对照。阊阖门、建春门、太极殿与永宁寺塔各对齐自己的图符中心。太极殿沿用独立图符。报告平面尺寸与图面简化体量单列。永宁寺九层有文献与调查材料支持，体量绘九层。艺术画中的小比例塔影简化，宫城北缘、六世纪古地面、古河岸和建春门跨图配准仍循 R4 边界。
- 全城视角使用平行投影，宫寺视角使用针孔透视。场景 JSON 保存相机、原 PDF 顶点、每栋建筑的来源和绘图尺寸。未经独立控制的文献关系保留在 R4。全景画不对 328 个无直接来源几何的对象另配坐标。
- 「对照四处建筑落点」以白圈显示模型投影点，以金点显示在成画上读到的位置。只在画面内部比较构图。比例、屋顶轮廓、住宅密度、人物和光照属于艺术取值。

## 图像、研究与验收

艺术图使用投影底稿绘制，采用1628 × 966原幅与900像素宽手机版。下载提供 WebP、两幅可缩放 SVG、场景 JSON、校验清单与离线 ZIP。网页在无 JavaScript 时仍可逐图阅读。在断网环境打开解压后的 index.html 可使用原幅、体量图及四处建筑卡。

现行 R4 与首页各增一个可逆入口。验收使用 R4 生产提交的页面指纹，逐字节还原插入前页面，核对 H2 两个分辨率的既有校验值，继续运行全项目原有研究与浏览器测试。发布、验收与六世纪史料续查分别记录于[固定交接](https://github.com/mechgouki/luoyang-city/issues/52)和[研究记录](https://github.com/mechgouki/luoyang-city/issues/47)。
