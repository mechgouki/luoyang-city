# P3 宫城阊阖门：局部图定尺与城市接合诊断

研究版本：`prosperity-gate-v3.0`。本轮将一张有比例尺的考古平剖图中可辨的门基、门道、阙基边线及连接关系转为**图内米制几何**，并明确它尚不能精确落入既有城市坐标框架。本轮不改变 P1 的城市来源点、P2 的工作轴、三个尺度片或永宁寺院界争议。

## 3. 只从比例尺计算图内米制坐标

20 m 标尺两端相距 81 px，名义比例为：

```text
s = 20 / 81 = 0.24691358024691357 m/px
```

两个标尺端点合计最多 3 px 的读图范围，给出比例的保守包络：

```text
s_min = 20 / (81 + 3) = 0.2380952381 m/px
s_max = 20 / (81 - 3) = 0.2564102564 m/px
```

这是一条横向印刷比例尺。本轮假设像素在两个方向等比例，**没有用第二条独立纵向标尺或外部控制验证扫描纵横畸变**。表列 44.5 × 24.4 m 不参与该比例的计算。

北箭向量为 `(-4, -59)`。它定义图内北单位向量 `n`，图内东单位向量为 `e=(-n_y,n_x)`。图内原点取上述四个门基角点的算术平均 `(271.5,138.5)`；这个平均仅是一个可复算的绘图原点，不是现场测定门心，也没有被证明与城市管理图的图符中心对应。

```text
n = (-4, -59) / sqrt(4² + 59²)
e = (-n_y, n_x)
q = p_px - (271.5, 138.5)
x_m = s · dot(q, e)
y_m = s · dot(q, n)
```

北箭相对图面向上偏左约 **3.88°**。以两端位置半径合计 3 px 作保守方向包络，角度约为 `asin(3 / sqrt(4²+59²))`，即 **±2.91°**。这只是低分辨率箭头的读图敏感度。原图没有交代这里是何种外部北向基准，不能将它认作已经验证的真北、网格北或磁北，也不能直接与 P2 城市工作轴作地理旋转校正。

转换保留点间距离的统一比例，不做非等比拉伸、透视校正或局部修正。下载的模型保留若干小数位供复算；页面通常只显示约数，数值位数不表示实测精度。SVG 原件对照图保持原件图面方向，下载坐标采用图内北向坐标轴，两者通过上述同一变换关联。

## 4. 本轮实际描了什么

本轮共 10 个可选构件。它们是 `ic_changhe_palace` 之下的读图构件，不新增或合并历史实体。

| 图层 | 数量 | 表达方式与边界 |
| --- | ---: | --- |
| 主门基主体 | 1 | 四个可辨外缘角点构成简化闭合线；突出漫道、连接基础不并入主体尺度。 |
| 西、中、东门道 | 3 | 只圈出基座间可辨中段；南北端线用于截取可辨段，不是封闭墙，也不表示全部通道进深。 |
| 西、东阙基 | 2 | 仅描可见实线与折角，保留为开放折线。黑色探方框不是阙基边，未用于闭合轮廓。 |
| 地下基础范围 | 2 | 跟读原图注明“地下基础夯土”的可辨虚线；按来源虚线显示，不混为地上外墙。 |
| 两侧连接路径 | 2 | 依可见基础走向取中心示意线，只表示走向和拓扑关系。线宽没有米制宽度含义，探方间缺口未补作测得结构。 |

原图中的后期沟、坑及零散柱础不在本轮描线范围。四处院落仍可从原件阅读，但没有充分辨识其完整实测边界，因此没有为它们补出米制院界。不得由这些线直接生成精确柱网、门楼体量、屋顶或有顶廊。

## 5. 与表列 44.5 × 24.4 m 分开核对

独立于比例尺读数，采用 [同一汇编第 1927 文件页、附录 2 的 Cgm-3 条](https://whc.unesco.org/uploads/nominations/1442.pdf#page=1927) 所列宫城阊阖门基尺度：东西 44.5 m、南北 24.4 m。该条说的是门基，不是完整两阙和院落群，也不能与内城西墙的同名城门尺寸混用。两项同属一份汇编，所谓“分开核对”不意味着已经取得第二套外部独立测量控制。

为避免旋转把轴向包围盒撑大，使用四边形**相对两边长度的平均值**，不使用图内北向坐标的轴平行包围盒。东西两边为 184 px、188 px，平均 186 px；南北两边约 103.044 px、103.005 px，平均 103.024 px。

| 核对方向 | 标尺换算名义边长 | 表列值 | 图读减表列 | 人工量读保守包络 |
| --- | ---: | ---: | ---: | ---: |
| 东西 | 45.93 m | 44.5 m | +1.43 m | 43.33–48.72 m |
| 南北 | 25.44 m | 24.4 m | +1.04 m | 23.58–27.44 m |

包络计算将每条边两个读点的合计 4 px 与标尺两个端点合计 3 px 作最保守组合：`(平均像素边长 − 4) × s_min` 到 `(平均像素边长 + 4) × s_max`。这不把四条边的读数当作彼此独立随机样本，也不以除以样本数或标准误缩小读图范围。

表值落在上述读图包络中。该事实**不能宣布已吻合或配准通过**，也不足以单凭小图断言考古表格与现场遗迹矛盾。差异可能涉及主体边界定义、示图绘制或印刷变形；本轮未能判定原因。保留原比例、读点、差异与对象定义，不反向缩放到表值、不设任意“通过阈值”。

## 6. 城市接合：保存已有位置，明确缺少的条件

沿用 P2 阊阖来源点：Xian 1980 / EPSG:4610 下的 `(112.6221536,34.7255900)`，以及项目既有同基准局部投影坐标 `(502.558775,-858.998246)` m。它来自管理规划图 06a 的概略图符，不是本次从小图获得的新经纬度。

阊阖与太极两个既有来源点的连线工作角 **1.128958°** 仍只用于 P2 阅读对齐。P3 接合图左侧显示这两个旧点和旧尺度片，右侧显示原件量读的局部构件，二者之间不画成已完成精确配准的同一足迹。

当前已核定的共同控制点为 **0**。尚未证明图内四角平均点与城市图符中心是同一测点，也没有核定原图北箭的外部基准。因此 `registration_verified=false`、`city_overlay_allowed=false`，`translation_m`、`rotation_deg`、`city_geometry` 及 `global_accuracy_m` 均为空。一个概略位置和一个未交代基准的北箭不能凭空产生可检验的定位精度。

进一步接合需要可辨识、相互独立的共同位置控制及其误差记录，并核定北向基准，或用共同控制独立解算旋转；同时核对扫描纵横尺度与使用的结构边界。这里列的是下一步需要满足的证据条件，不宣称这些材料已经取得。

永宁院界 264.889055 m 来源图间距与 212 m 表宽的冲突仍沿用 P2 未定状态；本轮没有移动院界、把塔心当院心，或借用本轮阊阖图的北箭替永宁结构定向。

## 7. 输出与有限验证

`build_gate_geometry(data)` 根据 JSON 返回图内米制构件、标尺和北箭量读信息、尺度诊断以及原样继承的城市接合状态。`render_gate_local`、`render_gate_city_link`、`render_gate_diagnostics` 分别产生原件对照图、接合条件图和尺度核对图；三图均为 1600 × 1100 逻辑视框。来源图仅放在局部对照 SVG 的独立 `source-layer` 中，可由页面开关显示。

本模块的验证针对实际剩余风险：确认原生图哈希；逐点验证统一比例与旋转保持点间距离；检查原始输入不被修改；验证 SVG 为合法 XML；确认三门道、两条开放阙基线与来源虚线没有被改为新城市地理轮廓；检查表列数值不参与校准、城市控制和配准状态不被升级。发布器和页面的构建、交互、下载及正式站验收由集成流程另行完成，不能用本模块局部核对代替全站发布验收。

## 原图双栏对照的几何含义

左栏是原生 555×434 像素 JPEG；右栏直接用源记录的 source_px 点位在同一原始像素网格描线，滑杆只调整右图 JPEG 叠加的透明度。不借助米制模型重配准。两图对齐不代表建筑原址经纬度已校准，也不代表未描绘区域不存在。P4 南北节点顺序与 P3 局部源图分开保存，不能直接推出实际门殿距离。
