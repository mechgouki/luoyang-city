# R9.1 城市空间总图与20项判断

本批承接已验收的 R8.1 / `fc62dd0fa439e01fbf13899fe8b9eea7f9c101f0`。用户要求将四节点研究集中落实为城市空间总图、空间判断—依据—图面变化对照表，以及进一步修订的 V13 候选图。本说明覆盖前两项；候选图单独保留修订与审看记录。

## 阅读入口与产物

- `luoyang-city-spatial.html`：一张城市空间总图、四个局部阅读窗和20项可筛选证据行。
- `city-spatial-r9/overview.svg`：可独立放大、点击编号回到证据行的完整总图。
- `city-spatial-r9/decisions.json`、`decisions.csv`：20项判断的完整字段、原文或既有核验摘要、原件定位、来源指针、图面变化与限制。
- `city-spatial-r9/source-audit.json`：原件续查的实际访问结果，以及本批能够支持的空间约束。
- `city-spatial-r9/manifest.json`：下载产物、输入文件与被保护旧成果的SHA-256。
- `downloads/city-spatial-r9.zip`：打开 `index.html` 即可离线阅读总图、表格和来源审计；旧专题与外部原件链接仍指向正式网站。

研究版本为 R9.1，实现版本为 `city-spatial-r9`。页面和JSON均记录构建的实际来源提交。正式发布与完成状态以当前主分支、Actions三阶段及固定交接 #52 为准，本说明不提前宣称验收完成。

## 几何与证据契约

主图使用 `city-atlas/atlas.json` 的图06a既有几何。源图点、原段、断笔与范围类型逐值保留；仅添加显示变换与注记，不闭合寺墙或缺失道路。原图对象另存 `data-source-geometry`，独立验收同时核实际SVG的路径或点值，不能只靠元数据声称保留。

四局部窗是无比例关系图，排版坐标不属于古代位置。西阳门、太极殿等引线明确是阅读参照，不是白马发掘区或司马门的地理锚点。2023司马门图六根路迹原子线及蓝色范围框保留独立来源坐标；蓝框不作仓墙。门下暗渠局部来源图、外郭道路报告与图06a没有共同配准，不能据同名门址补出桥头或渠口。

对照项每项保存 `prior_finding_ids` 与真实JSON指针。原文引句标 `classical_text_quote`，其他摘述标 `prior_review_summary`。R7来源的访问记录明确归到 `provenance_stage=R7.1`，不把“上轮取得”改写为本轮再次取得。两种校本不计作两位独立历史证人，采访报道也不另计独立考古发掘。

## 原件与未定项

1993报告原刊602—608页、完整图、图例和末测点仍缺。2011简报仍仅有重印本、馆藏及目录线索，完整原页图版未得。阅读入口转向登录页不构成取得全文；本轮访问细节见来源审计。2022运河报告继续暂缓。

516—528年是综合研究窗口。永宁寺创立年不能替代所有上部建筑完工年；道路宽年代不能证明每段路面在目标窗口同时使用；527事件不扩展到城东全部桥梁。

## 交互与验收

页面提供六种总图视窗、放大缩小、四向平移和当前视窗复位。手机局部窗保留740像素画幅并允许横向滚动，避免把图中文字缩得过小；放大后可用平移按钮或图框方向键查看边缘。地点/道路编号/关键词检索可与四节点和三种依据性质筛选组合。网址参数 `q`、`node`、`basis`、`view` 可刷新恢复；`#decision-SP01`至`#decision-SP20`为独立证据锚点。图上链接命中被过滤行时自动清除冲突筛选，确保目标可见。主动筛选隐藏当前锚点时移除旧hash，避免刷新覆盖筛选意图。脚本关闭后总图、全部判断、来源和下载仍存在。

构建函数 `tools/city_spatial_r9.py:build(site)` 在 R8之后运行。它保存旧release原字节，不修改旧页面、首页或旧图片；后续V13二修构建负责统一入口。R9元数据中的 `predecessor_release` 用于后置版本在旧验收器中恢复明确前置状态，不能放宽或跳过旧规则。

验收包括：真实来源指针、20项CSV与JSON一致性、原几何逐值保护、每个SVG目标、下载哈希、离线包、桌面和手机筛选、URL恢复、图面复位、键盘导航与无脚本阅读。正式站验收和长期证据按AGENTS.md执行。
