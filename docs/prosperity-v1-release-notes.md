# 盛时洛阳 P1：文献审校与来源图城市骨架

本版落实用户2026-11-14确认的盛时优先路线。界面版本`prosperity-v1`，既有研究批次和源实体身份保持可追溯。正式发布须由对应PR、生产Actions的build/deploy/verify-live及站点构建记录共同确认。

## 这版解决什么

先前文献图可以阅读相对关系，但尚缺一套能与来源图坐标相接、同时保留证据边界的城市分布工作层。P1以同一份339地点名录连接文献图、来源图骨架和计算斜视图，并为30项来源几何提供独立档案。没有可靠绑定的城墙、道路、云龙门与太极殿等，不因此变成新增的旧名录实体。

### 文献平面

183条旧证据完成本轮电子文本追溯：172条旧引按规范化节录顺序匹配，11条主异常或特殊抽取经人工上下文处理；另对读10处次选版本差异，保留读法条件。225次逐来源检查中201次直接匹配，其余由14个主异常来源实例及10次版本比较解释。电子匹配不等于古刻逐叶校勘，也不证明实体身份、同期存在或古址位置。

236处字面约束共93种目标：198处仅可作为唯一目录名称链接，38处按地域、集合、范围、回指等语义处理。11项读图决定公开可查。G13更正“都堂在柰林西”“堂东扶桑海”，把百果园归属的篇章概括与正文分开；NG15将“城之西北门也”从古籍引文中移回周氏现代校注。G15沿用B8已核更正。

所有339实体与179旧交互目标保留。共享阅读位置先展示成员选择，选择成员不会产生新的独立地理地址。实体档案继续呈现时层与未定断代。原始研究记录不覆盖，新工作层保留旧引、当前读法与出处。

### 地理位置依据

实际取得的[申遗原件](https://whc.unesco.org/uploads/nominations/1442.pdf#page=3457)第3457页图06a为2012年保护管理图，明载西安1980坐标、1985国家高程基准、1997航摄与1999实测底图。图04及附录表提供名称、分期和尺寸旁证。以16个印刷经纬刻度重算30项位置与范围，保留原PDF矢量顶点、刻度、系数、页码与SHA256。

数据采用来源坐标系EPSG:4610，并明确经度在前；它不是RFC7946的WGS84 GeoJSON。图内拟合残差只反映刻度再现，不能当作地面精度。100m是工作展示容差，非原件发布精度或统计置信区间。未做WGS84基准转换、现场核验或古代地面建模。

13条明确绑定对应11个旧实体。金墉仅绑定丙城组成部分；永宁寺围墙与塔基分别记录；宫城阊阖与城西同名门分开。附表只属东汉或东汉—魏晋的雍门、太仓、武库与冶铁址不进入盛时默认活动层。小建筑放大图符只用作中心位置参照，不能直接成为建筑足迹。

### 城市分布与布局鸟瞰

两图使用相同来源几何与同基准局部米制投影。宫城推定包络仅填色、不描出伪实证北墙；实际地下墙用虚线。内城南墙和宣阳门保持未知。外郭相关遗存以概略范围表达，未补成连续精测墙或完整坊里。

现代洛水中东段与邙山方位独立分组，网页默认关闭，可单独打开。它们不替代北魏河道与地形。鸟瞰的抬线为7显示像素，不代表古代墙高，也没有以艺术填充推断民居密度、坊墙、塔高和建筑立面。

## 页面与下载

### 历史地形与建筑尺度继续推进

申遗原件的5条具体线索进入页面：隋后洛水向北改道、南墙受改道毁损、东西城壕的局部淤积/埋深、宫墙多期剖面。每条给出页码、时空范围、布局影响与限制。这些支持古今河道分层和局部地层判断，尚不足以绘出确定古河槽或连续古地面。

另核得8组建筑尺度与后续体块依据，详见[尺度说明](prosperity-building-dimensions.md)。宫城阊阖门基44.5×24.4m、太极殿约100×60m、永宁塔基约38.2m方形可约束后续平面模板。太极殿约6m是地下夯土深度，永宁塔基2.2m是残高，均不当作盛时建筑高。资料中的未知高度和屋顶继续为空，不从缩图图符尺寸推算。

### 可访问的成果

- `prosperity.html`：三种视图、检索、区域/类型筛选、拖动与缩放、实体/共享组/来源要素深链接、来源与审校目录。
- `downloads/prosperity-v1-atlas.pdf`：6页，含全城文献图、宫苑关系、地理概览、内城骨架放大、布局鸟瞰、依据边界。
- `downloads/prosperity-v1-entities.csv`：339项地点与定位状态。
- `prosperity/text-review.json`、`geographic-evidence.json`：完整本轮审查记录。
- `prosperity/terrain-constraints.json`、`building-dimensions.json`与尺度说明：5条地形约束及8组后续体块依据。
- `downloads/prosperity-v1-package.zip`：图件、数据和坐标约定说明。

不重发布1GB申遗原件、整页来源地图或完整现代校注。保留来源链接、哈希、定位与必要研究摘录。

## 验证与后续

新增23项语义检查覆盖古文/现代注分层、源坐标轴序和重算、同名门、年代边界、缺失墙线、包络不描边、既有ID/共享锚点、原资产哈希及下载完整性。现有语义和浏览器门禁继续执行；新增浏览器旅程覆盖桌面/手机、选择、筛选、深链、真实图件、现代参照开关与来源档案。生产部署后仍须验证全部资源哈希、构建提交及实际操作。

P1完成可使用的第一版研究工作层，未宣布四阶段全部完成。后续继续补足北魏古河道和地面、遗址分期、建筑尺度与构成，再从已经建立的布局深化盛时城市全景；毁后城市继续后置。
