# P4.7.2 城西门道与坊寺

R1 接续已验收的 [P4.7.1](https://github.com/mechgouki/luoyang-city/commit/0a2f497f2bf4e3f5497272b5f24a420309039b7e)。[城西专题](https://mechgouki.github.io/luoyang-city/prosperity-city-west.html)从北门与金墉专题进入，也可直接打开任一 WR 记录。全城共同视图、B5原专题、水陆骨架及西阳门外道路考古均有返回入口。

## 如何读这两张图

门址图在同一06a来源图框显示三组墙线、八条道路残段与三个图符，逐段采用P1保存的原PDF顶点。西阳门 Cnm-3、西明门 Cnm-1 是西墙参照。宫城南面的阊阖门 Cgm-3 仅用于辨名。三图符的来源时期分别为北魏、东汉至北魏、魏晋至北魏。资料为2012年保护管理图，底图采用1997年航摄及1999年测量。P1地理数据为西安1980（EPSG:4610），100米为工作显示容差，绝对地面精度未知。三条文献门外御道都没有从内城残线外推。城西阊阖门没有对应的来源图符。

另一图分栏呈现门序、相对方向、里属、用途与分期。图框宽度、间距、箭线及框在版面上的上下位置均属于编排。每个框可点到对应证据。名录涵盖22个实体，其中19个仍未定位，包括城西阊阖门、承明门和三条门外御道。页面提供按对象或门道阅读、逐条深链接、放大横移、来源道路开关与无脚本阅读。

24条均比对了B5原引、实体列表、核心解读、时层说明、P1文本层及实际匹配行段。两个现代整理本的六个电子卷册同属一个原书家族。P1本组24条匹配的主引均据周本，范本异读按B5的参校记录标明。两条数据源各自完整可追溯。24条电子匹配通过，24个 `manual_context_review` 及24组证据坐标均为空。B5原约束数组合计24项，其中含复述与定性景观，计数不表示新增空间关系。逐条展示决定位于[独立工作层](../research/prosperity-v4/west-472/crosswalk.json)。

WR08保留周本“〔立〕”、节略号及“懷所居之堂”，范本“環”及其解释另列。七佛为堂内造像。WR09的永熙砖塔（532—534年）后于盛时，塔层数未记。WR12石基的材料说明限于基座，WR13普泰末毁损限于寺门。WR19—20盛时采用“城阳王徽宅〔后宣忠〕”，529年北海败散后方兑现舍宅；WR21不向王典御寺传递该年代。卷四西阳门外白马与卷五瀍涧附见白马保持两个目录条目，同一性待考。
