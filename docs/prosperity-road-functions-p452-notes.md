# 盛时洛阳 P4.5.2｜道路残线、宫前御道与城市功能分区

研究时层：北魏洛阳516—528年盛时文献综合；图示遗址、魏晋复用结构、近现代水系及民间市场叙述不合成单年确证街道地图。

## 本轮确实完成的进展

已有P1来源地理图（2012年申遗保护管理图06a，图注西安1980坐标网格，背景1997航摄／1999测量）共 **30项几何**。筛出其中**8项来源图道路折线**（2条铜驼／宫南T形相关线，3条东西横道，3条南北纵道），在完全不变的原P1 SVG几何上添加独立可点击高亮，而不是另绘整条北魏路线。

八项分别为 `Lz-3 geo-tongtuo-avenue`、`Lh-2 geo-tongtuo-cross-street`、`Lh-1 geo-road-east-west-south`、`Lh-3 geo-road-east-west-middle`、`Lh-4 geo-road-east-west-north`、`Lz-1 geo-road-north-south-east`、`Lz-2 geo-road-north-south-mid-east`、`Lz-4 geo-road-north-south-west`。**来源图的多折线组数**只属于图示遗址片段的制图结构，不等于“8条完整可通的北魏道路”。已报告铜驼大道现存段长约**1650米**、宽约**40–65米**；其他道路不能从SVG线宽直接生成米制路宽，亦不能套用这项道路的宽度范围。

## 五类城市功能仍属于证据名录，不是用地密度

1. 寺院：永宁寺有旧来源图概略遗址参照，塔北佛殿的书面关系不构成新的建筑地理点或屋顶高度。
2. 官署/学校：左卫、右卫、司徒、太尉与国子学共同列在宫前段，但除已有的文献关系外尚缺足以描出各自真实城内院墙位置的共用勘测点。
3. 道路/桥梁：建春第一石桥、东石桥、永桥为独立旧实体；不能把颓桥事件、南北通道、浮桥结构交叉赋予。
4. 商贸市场：洛南四通/永桥市为同一条市场的正式/俗称；卷二归正里鱼鳖巷市是另一条原文语境，鱼货相同不推出地点相同。
5. 里坊/居民：建阳/绥民的桥北大道两侧，归正里（吴人坊俗称）的里属，仅是文献关系，不提供其外轮廓。

**不统计或推算人口密度、市场店铺数、街区面积。**古代地面高程、古桥实际位置、道路贯通性、北魏洛水及伊水河道都需要额外原刊测绘和分期来源，仍未解决。

## 技术实施与独立验证

- `research/prosperity-v4/road-functions-p452.json`：8条原路迹ID、5组文献情境/证据等级、5类非地理功能及禁止反推的假设。
- `prosperity-road-functions/road-evidence-map.svg`：复用旧P1 `prosperity/source-layout.svg` 全部30项图形，保留源图道路的原有 `d` 路径字节；只在上方叠加8个有编号的同路径可点击高亮。图标与交互层不产生新古坐标。
- `qualitative-relations.svg`：五组分离的文本关系板，不在画布上拼成能导航的街道路线。
- `function-layers.svg`：寺院、官署学校、桥路、市场和里坊的非地理名录板。
- `prosperity-road-functions.html`：8条道路与5组关系各自可键盘/鼠标选取、深链接 `?road=D01&context=R02`，支持手机和无JavaScript静态查看；公共下载 SVG、PDF三页图册、JSON、两份CSV和ZIP。
- 入口从前一阶段 P4.5.1 研究网页连接。此前P4.5.1原HTML保留校验归档，首页H2用户明确批准的全景高清图、现有P1—P4.5.1资料与对象旧ID全部不动。
- 研究图网页和PDF必须经GitHub PR的结构/语义/浏览器测试，以及合并后main `build → deploy → verify-live` 全部通过，才标记为正式上线。
