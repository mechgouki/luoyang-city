# 双图 B5：城西三门道与历史地图基准调查

日期：2026-11-13。续接基线：`d3f1177488275062e89977926908460b331c5e4f`，B1—B4及两幅历史图扫描已发布。

## 为什么做这一批

R02城西门道的已有文献锚点仍多用通用寺名符号，寺序不完整、宅改寺年代及后出塔构件容易被同一画面误读。地形线虽已完成扫描图格网内部校准，原纸图的水平基准与数字化时赋予的坐标定义仍需分开查证。

本批在同一母图更新8个寺宅及3座城门的类型表达，建立WR01—WR24证据、L07文献分区、寺序约束板、宅寺塔时层板和来源表。首页已有实体可以直达相关证据。新专题为`dual-west-roads.html`，独立基准专题为`historical-datum.html`；B1—B4和原始37页图册继续可用。

## 文献与绘图决定

- 大觉在融觉西、永明在大觉东，不足以给出永明与融觉先后。永明继续作为未定位旁注；两种严格先后只是可容纳关系的例子，也不排除东西坐标相同而南北不同。
- 城西阊阖与宫前阊阖保持原有不同ID。三座城门使用不数层的类型符号，不声称已知楼高或平面。
- 宝光在西阳道北；法云在宝光西、隔墙并门，法云自身路侧未独立明记。临淮王宅只按法云北的关系解释，不补院界。
- 宣忠在516—528综合层保留城阳王徽宅。529胜负未决时的舍宅愿与北海败散后的兑现分开登记，寺院竣工日未载。
- 大觉永熙砖塔晚于工作时层且未记层数；冲觉五层追福塔不据此写成516—528全程已完工。融觉五层、宝光三层石基、王典御门前塔分别记录条件，不在主图批量添加塔。
- 王典御继续作为未定位旁注。宜年两宅不由共同目录锚点拆出地块。两条白马寺记录保持身份未决，不强合也不宣称必为两个独立寺址。
- 六个电子卷册来自同一原书来源家族。正文、校读、采用解释与图面安排分栏记录；未完成古刻逐页校勘。

## 历史地图调查的实际增量

两幅原图各截取7类边栏，共14张无标注原像素PNG。生成前核验原始扫描SHA-256；每个裁片保存源像素框、尺寸和输出哈希。

查明原馆固定版本FGDC XML的第二处理步骤：哈佛在2005年2月为整套数字影像统一赋予WGS_1984，并记录AMS未随该系列公布关联水平基准。所用4组控制来自角点附近的印刷UTM坐标。该数字工作定义不证明原纸图原始基准。

NI49-7、NI49-8转换RMS分别记为23.98942米、48.70132米。它们与B4每幅8点拟合、5点同图留出的数字影像、控制方案及统计对象不同，不作地面精度排名。两馆图号、版次、印刷年月吻合，但扫描尺寸不同，不移植像素变换或world file。

原纸图水平基准和地理CRS继续为null；本项目未完成WGS84配准，地面精度未评估。具名稳定地物0、获准地面控制点0。审核队列的3类待查方向与2类排除规则不当作已找到的实体。古址经纬度、古河道均新增0，现代DSM未修改。

完整来源、固定版本、XPath、字节数及SHA-256见`historical-datum-b5-research.md`和研究JSON。
