# v2.7 水陆网络与事件作用范围 / 网站 0.4.0

## 目的
承接 v2.6，检验跨区连接而不是仅增加手绘线条。水流、叙述通行、跨越、对齐和身份候选分别处理；事件不自动传播为整组建筑或后续所有年份的状态。

## 交付范围
- 20条文本段落卡，取《洛阳伽蓝记》与《水经注》对应电子正文；保留来源、段落锚点与解释边界。
- 分段水道和桥路提及节点。不因为都叫阳渠就合并；W浮桁提及也未默认等同L永桥。
- J1跨源建春外水段对应、J2南渠/西明支渠对应、J3东石桥/马市桥对应、FLOOD条件溢流；均默认关闭。
- 16种开关组合 × 3种来源保留方式，共48情形、480个查询结果，输出边ID、节点、依据和前提作为路径证书。
- 四张文本网络SVG：东部两桥、宫前支渠、城西—城南、永桥两岸。不按地理比例，不以行的位置暗示南北。
- 10项关键事件及339对象覆盖账本。日期、对象、构件、用途或城市总括分别登记；覆盖账本不是339条年代考证已完成。
- 网页方案开关、删源、路径展开、逐条证据、事件年份与对象过滤、账本、CSV/JSON、独立可打印报告与可复现源文件ZIP。

## 条件性研究结果
1. W广莫门北至建春桥下、东出阳渠至马市桥有连续文字水流链；与L具体水段续接须J1。没有J1时“未建立”不等于历史不连通。
2. 宫前南注南渠与西明支渠的对接须J2。不同阳渠出口没有因为同名就被当成一点。
3. J3只合桥名，不产生水流；水经中宣阳门对宫门、南直浮桁也不提供谷水汇入洛水的证明。
4. 长分向洛水分流只在启用文本所述溢流条件时出现，且保留“中朝时”回溯范围；不宣称北魏某年发生或为常流。
5. 四月行像路径与永桥往来分属不同叙述作用域，不能自动拼为全年通行图。
6. 527雨毁属于建春门石桥；534永宁塔火不等于整寺毁尽；开工区间不提供完工年或永久在建状态；546石经迁出不等于国子学堂原址消失；547原序是城市总括而非逐址清单。

## 不变量
原339实体、482关系索引、179标记、11区域、37图页及PDF、v2.5和v2.6所有公开数据与图纸未改写。仅网页入口/首页最新提示增加，v2.7由独立数据、程序和资产组成。所有地图几何仍保持原基线；新图是拓扑研究，不是水文实测或古里米制复原。

## 资料核查边界
本次核到电子正文、范校电子重排PDF文字及四部丛刊本电子转录，未完成古刻书影逐页校勘。PDF第43—44、100页属于CBETA重排页，不冒称原印本页。W包含多个历史时层，同一段文字次序不自动证明516—528某日所有设施共存。L的多个整理版本同属一来源家族，不用引用数量投票。

## 重建
先按现有 v2.6 构建链生成 `_site`，再运行：

```sh
python -m unittest discover -s tests -p test_v27.py -v
python tools/network_v27.py
node --check networks-v27.js
python tests/browser_v27.py
```

旧版所有测试继续执行。正式部署后校验整个公开文件清单及新数据，并在真实HTTPS下运行v2.5/v2.6/v2.7三套浏览器测试。PR成功不等于发布成功，Issue #5仅在main的build/deploy/verify-live均成功后关闭。
