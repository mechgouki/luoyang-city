# R7.1：四处关键城市节点与首页依据导览

研究窗口：516—528年。首页继续使用用户批准的 `panorama-approved-v12` 全幅图。

本批将四处节点的空间判断整理为可读地图、逐段证据与首页导览，不改变 R4 原有的339个对象、R6.2的84条道路来源记录及34项水系索引。新专题为 `luoyang-city-nodes.html`；研究版本 R7.1，实现版本 `city-nodes-r7.1`。正式完成以该提交的主分支构建、部署、正式站验收和 #47／#52 的长期证据为准。

## 交付内容与统计口径

- 一张城市联读总览：2012年图06a的遗址图与黄学超图1的水系图分框呈现，四处节点通过已有参照对象进入。白马寺只以西阳门帮助查找地段；司马门另读2023年来源图，二者均不据此新增全城地理坐标。
- 四张局部图：宫前与永宁寺、白马寺坊门与坊街、司马门与仓区、建春门三桥。
- 32条核验判断、32条关系。关系既包含原文明示，也包含报告局部接触、作者解释和未决接续，数量不表示32处新测定位置。
- 28条逐段来源记录：四节点涉及25条既有记录，另加首页宣阳门外、永桥南御道和永桥3条。它们保留原ID、原起讫描述、原时段、原图引用与水系限制，不是28条独立古路。完整84条道路总表继续在原道路专题查阅。
- 9项相关水系记录与完整339／84／34索引相连。宫前铜驼夹路支渠没有在W01—W34中独立登记，不拿其它地点的W04泛称填充该局部。
- V12画面六个依据入口：宫城与阊阖门、永宁寺、宫前大道、南城门、洛水、永桥与两岸。热点仅为画面导航，不进入地理数据，也不产生城墙、桥头、古岸坐标。
- 可下载SVG、UTF-8 BOM CSV、完整JSON、版本清单与离线ZIP。CSV的数组／对象单元格使用JSON，未知值保留`null`，不写为0。

### 宫外仓窖的统计范围

本轮重新取得[新华社2026年1月16日报道](https://www.xinhuanet.com/20260116/691942d5375a4060b5bfd0d0363e1cf8/c.html)与[人民日报2026年3月25日报道](https://paper.people.com.cn/rmrb/pc/content/202603/25/content_30147047.html)。前者分别叙述14列、12排、168口系统勘探和13口发掘；后者另述南北向3排及13口发掘。现有报道没有确认两组排数的空间统计范围相同。本批不直接判作矛盾，也不推定3排必定就是13口发掘的分布。图面保留各自来源范围，暂不拼成完整同期仓窖网格，不以窖数生成地面房屋阵列。

### 本轮原件访问与限制

本轮重读《洛阳伽蓝记》卷一、卷二相关电子文本，明确正文、周氏现代夹注与本项目解释的层次；重核钱2018图二公开重刊、2023司马门位置图和2026宫外仓区现场图，图像哈希与既有记录相符。2017年度宫院发掘汇报全文可读，约4.7米确属院内夹道。

2025白马寺年度转载本轮正文不完整且直接请求403，相关4.6米等已核提取沿用前批，不宣称本轮读到原刊全文。河南官方页面仍有超时／503。1993外郭城勘查原刊602—608页及完整附图本轮未取得，仍不能将推定线升级为实测线。2022运河报告继续依用户决定暂缓。

## 图面、表格与首页的回查路径

首页“查看画面依据”进入V12导览；六个画面热点打开对应说明，再进入节点或逐段证据。总览节点进入独立局部图，图中道路／关系标签打开固定`segment-ID`记录；记录中的“回到图面”定位原有图元，键盘焦点与URL同时恢复。资料筛选支持关键词、节点和图面依据。

R6.2另补记录到原图元的往返：`#ID`继续打开旧证据卡，`#map-record-ID`聚焦原图元并恢复所需图层，不为索引条目假造路线。下载ZIP包含新页面、图、数据、样式、脚本和V12原字节图片；不依赖联网读取核心资料。无JavaScript时仍能展开原生证据卡与阅读全部正文。

V12在首页两个入口的原图、手机版图与全幅布局保持一致；新增链接和一句版本说明有精确可逆合同。新增前HTML另存，校验时去除声明的三处改动须还原到逐字节一致的前版。R4／R5地图和既有下载保持各自历史字节与来源指纹。

## 本批小修与验证

`research/current-state.json`统一登记研究批次、已批准首页和封存底图；`tools/current_state.py`同步README与接续文档的当前摘要，不覆写历史批次原文。登记中的“上一已验收发布”保留真实前次证据，不能用工作分支构建伪称新批已上线。

`tools/build_all.py`统一全部构建调用，CI与本地使用同一顺序。默认含PDF准备；CI在准备与站点构建之间保留原数据测试。构建使用完整40位来源SHA，保护旧版固定指纹，不以缩短SHA的本地占位符替代。

本批新增核验覆盖原数据保留、来源JSON Pointer、原图几何、未知端点、分期、CSV／JSON一致、离线ZIP、主页可逆改动及新旧图文往返。浏览器验收检查桌面、手机、深链接刷新、键盘、筛选、真实下载和离线／无脚本阅读。CI沿用Playwright 1.57.0固定镜像；若本机镜像不可下载，只将系统Chromium用于明确标注的本地预验，不替代CI门槛。
