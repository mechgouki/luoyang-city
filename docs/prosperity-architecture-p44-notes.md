## P4.4 核对出的三组“看似接近但不可平均”的资料

1. **东閤门中间一间**：2016年说门道约4m；2018年说面阔4.3m（础心间距）。两者测量语义不同，不平均到4.15m，也不简单断言同点测量冲突。
2. **东閤门侧间进深**：2016年记2.3m；2018年稿称单间础心至墙心2.9m。发表阶段／起讫点差异未核定，保留双值，不以尺寸片强行合成。
3. **院落西端单门道**：2016年记东堂北铺砖路西端约3.5m；2018年记东堂北宫院西端屋宇式约4m。没有完整原图共同端点前，不把两处文本自动合并为同一对象。

## 建筑比例的分层原则

- **A层：有考古报告的台基、门道、柱础、开间数、墙宽。**数据到哪里，图到哪里。
- **B层：研究者解释的承重形式、上层阁道、楼观等级。**可用虚线解释，但不给古代高度、屋顶曲线或饰面。
- **C层：将来用于叙事全景的艺术表达。**灯光、彩绘、坡度、门楼层高、人马密度都不属于历史证据。这一层暂不进正式“已核建筑”图。

一期图面采用：六类门制比较、东閤门量距异记、以及主宫仪制与廊院关系三张；不同板面**不允许彼此按画面距离套合成全宫地图**。

## 下一步研究要求

1. 回到2018原刊图六—九，登记图件扫描、比例尺、已用栏目与原始发掘图出处；分别审核本轮3组可能异记的起讫点。
2. 核查东閤门下方通行与上方阁道方向，同时用2017宫院院门、双阙门与廊庑分期资料，形成能进入北魏盛时的独立结构类目。
3. 在统一的城市范围图上只给出能证明的**类型分布**，未定院墙与未见上部结构不以屋顶批量填充。
4. 在地形与建筑分布证据足够后，从同一布局生成**候选全景**交用户评审，未获确认不替换第八版首页主图。
