# 盛时洛阳 P4.1 — 宫城原刊图证、编号与量距异记

研究范围：P4 中轴三门与太极殿。继 P3 取得阊阖门原生考古 JPEG、P4 整理 95/80/300 米与太极殿尺度之后，本轮专门核对 **2009、2010、2011、2013 四份奈文研机构公开原刊**与早期中文报告的差异，不增加未证古代绝对坐标。

## 1. 一号门究竟是什么

- **2009年**《奈文研纪要》p.23将阊阖门记作宫城正门，并以其北侧为二号宫门调查地。
- **2011年**《奈文研纪要》p.6 第2节列出1号、2号、3号、4号太极殿、5号西南隅建筑遗构，其中1号为宫城正门；图7以1号门为中轴南端。PDF可见有 OCR 将“閶闔門”误转为类似“門間門”的错误，不能把OCR错字当新门名。
- **2013年**《奈文研纪要》p.52图69在宫城南端同时出现“1号門”与“閶闔門”两个标签。从图面和2011年文字上看，指的是**考古编号／历史命名**，并不是另有一座更南侧的独立第四座宫门。

结论：对象身份关系可以登记为 **1号宫门＝阊阖门**，但这一判定不意味着2011/2013图版可以和 P3 另一张考古平面做绝对坐标上的直接拼接。旧P4使用四个轴线节点，**不增加**新实体。

## 2. 三号门至太极殿：200与300米

| 来源与发表阶段 | 原始报道 | 用旧 P4 另外两段95m、80m相加 | 与另一份约460m全程报道比较 |
| --- | ---: | ---: | ---: |
| 奈文研2011年报告（p.6） | 三号门至太极殿 **约200m** | **约375m** | -85m |
| 钱国祥2012年报告 / 同系论文日译稿 | 三号门至太极殿 **约300m** | **约475m** | +15m |
| 洛阳市考古研究院2024年机构报道 | 阊阖门至太极殿 **约460m** | 直接约值，非以上分段累计 | 独立保留 |

这些数字均是文献记录的“约值”；并非各篇都明确给出坐标、测距基点和测线。100米差异很大，不能默认为通常的测量误差；但在取得对应原刊实测平面、端点与分期之前，也不能断言两个作者在同一基点/同一语义条件下互相矛盾。2012日译稿及钱国祥中文稿、奈文研各篇源于同一中日宫城考古项目，不能按论文篇数投票。

## 3. 二号宫门南北尺度的历史发表差异

奈文研2009 p.23 二号门发掘初期记录约 **44.5×23.0m**；奈文研2010 p.14 在新一年的断割调查报告中记录约 **44.5×24m**。这一差异需要回查可读图版的实测界线和基址口径，不能直接归为作者抄错或测量误差。两组数字同时进入本批 CSV/JSON。原P4展示约44.5×24m，仍属于较后阶段发表口径。
