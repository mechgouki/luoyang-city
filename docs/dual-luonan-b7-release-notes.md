## 文献与图面决定

四馆道东、四里道西，馆里名单涉及周、范整理本中的校补及馆／里校改。目录编号不表示南北次序，制度对应不证明一一对街。吴人—金陵—归正、北夷—燕然—归德两段明写三年；扶桑—慕化、崦嵫—慕义不自动补上同一期限。雁臣季节性入侍、正光元年来朝个案与一般授宅叙述分别保存。

萧正德正文来降年与周注所引纪年分列；先居馆、筑宅与后来舍宅不共享一个营建日期。归正寺仍属未定年旁注，不能用523加三年造出526建寺。萧宝夤归正里宅后迁永安里，在516—528工作层标为旧宅附见；不能与萧正德或归正寺合并。菩提寺只有慕义里属的明确关系，寺院成立年与里内位置未定。

鱼鳖市属于归正里居民自立巷市；不能继承卷二段首小市北张景仁现宅的地点。四通市仅明确洛水南，永桥市是俗称，不提供御道路侧、距桥距离或市场边界。两市继续分立。

永桥保留原有浮桥图符及绘图锚点；神龟为常景作颂时，不作为创建年。两岸华表保留附注，原文高度与注引根数不变成建筑尺度。两坊保留永桥南、御道东关系旁注；白象入贡年不等于建坊年，狮子永安末、普泰事晚于工作层。圜丘仍为南向参照，不绘实体祭坛或伊水古河道。

当前母图深化7组阅读表达：四里、四馆、永桥附注、圜丘方向，以及寺院、鱼市旧宅、四通市三个旁注组。所有原有世界图层子对象原样保留，仅对其中32个加语义分组，再添加旁注文字。没有把群组成员拆成地点，也没有新增独立址点图符。永桥和该段御道原本就没有独立交互marker，本批不凭空增加第180个目标；仍可通过既有搜索条目和专题进入依据。
