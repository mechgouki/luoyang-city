## 重建与测试

```sh
python tools/assemble_pdf.py
python tools/validate_site.py
node --test tests/map-interactions.test.cjs
python tools/build_site.py
python tools/research_v25.py
pip install playwright==1.57.0
python -m playwright install chromium
python tests/browser_v25.py
```

专题生成器仅写 `_site`，其JSON/CSV/SVG/HTML可复现。网页入口由构建阶段加入，不覆盖原始v2.4图册。CI在普通PR里运行构建和本地HTTP浏览器测试；仅main部署；部署后独立verify-live确认实际提交和每个公开文件哈希（.nojekyll是构建控制文件，不属于公开网页资产）。

本地浏览器受环境策略限制时，不以离线DOM演示代替真实网络验收；以GitHub Actions的browser和verify-live结果为准。故障将留在任务日志和测试证据中。
