# P4.7 城市分布共同视图

研究日期：2026-11-19。对外版本为 **P4.7**；文件和构建器中的 `p470`、`common-470` 是本批内部标识。接续P4.6.9水陆骨架与P4.5.1—P4.5.3城市内容，形成独立页面 `prosperity-city-common.html`。本说明记录交付范围、数据身份和研究边界；最终提交、生产运行和正式站验收状态以[固定交接表 #52](https://github.com/mechgouki/luoyang-city/issues/52)的最新记录为准，不由本文件提前认定已上线。

## 这次共同展示什么

共同视图让读者在一个入口选择已有建筑参照，阅读宫前、建春和洛南的城市功能与文献关系。来源地图提供现有图形的位置依据，关系面板提供原文能够支持的方位与归属；两者通过已有对象身份联系，不将关系面板的排版当成地理布局。

| 内容 | 数量 | 统计含义 |
| --- | ---: | --- |
| 同源绘制要素 | 25 | 选取06a已有几何，其中24项为遗存图层要素，1项为近现代洛水参照；包含概略图符，不是25处新测古址 |
| 默认显示的遗存要素 | 24 | 包括来源图城墙、门址、建筑参照与道路残段；保持各自来源精度和时期 |
| 近现代洛水参照 | 1 | 1997航摄／1999测量背景中的参考线，默认关闭 |
| 可选建筑卡 | 4 | 沿用P4.5.1的C01—C04，建筑卡与文献节点分别计数 |
| 文献城市场景 | 3 | P4.5.3的K01宫前、K02建春、K03洛南 |
| 场景对象 | 20 | 既有对象ID；并非20个已定位建筑 |
| 城市关系 | 17 | 16条A层直接文字关系、1条C层条件解释，逐条复用原记录 |
| 时间事件 | 2 | 建春第一石桥527年颓毁、东石桥280年建造记述；不计入17条空间关系 |
| 功能类别 | 5 | P4.5.2的T01—T05，共分类15个对象；另5个对象保留为关系参照 |

25项是本视图的选择范围，不删除或重写P1的30项来源记录。遗存图层中的门址和建筑中心图符，不因进入共同视图就获得现场角点、完整足迹或516—528年逐年的使用证明。近现代洛水不计入24项遗存，也不作为K03古洛水的岸线。

## 主图与建筑卡的身份

主图沿用2012年申遗保护管理图06a的原PDF点几何；原件位于UNESCO 1442材料PDF第3457页，背景注明1997年航摄、1999年测量。原图缺口、多段线和图符形态按来源保留。P1另存的地理坐标属于西安1980／EPSG:4610，不能默认为WGS84。共同视图不增加地理转换或古代地面。

八项道路仍为D01—D08对应的来源图残段：Lz-3、Lh-2、Lh-1、Lh-3、Lh-4、Lz-1、Lz-2、Lz-4。不补断口、不延长到城门或古河岸、不根据相交或平行外观生成可通行路网。来源图铜驼大道与文献宫前御道没有获得全段同体的身份绑定。

| 建筑卡 | 来源图参照 | 可读内容与绑定界限 |
| --- | --- | --- |
| C01 宫城阊阖门 | `geo-changhe-palace-gate` | 沿用`ic_changhe_palace`与K01既有绑定；同名的内城西垣阊阖门不并入 |
| C02 内城建春门 | `geo-jianchun-gate` | 沿用`gate_jianchun`与K02既有绑定；门址图符不给两座石桥继承坐标 |
| C03 太极殿 | `geo-taiji-hall-reference` | P451的`entity_id`仍为`null`；不新增P453对象或自动挂入K01 |
| C04 永宁寺塔基 | `geo-yongning-pagoda-reference` | 塔基为寺院组成部分的来源图参照。阅读K01使用的是P453已有`geo-yongning-temple-walls`—`ic_yongning`绑定，不将“寺在御道西”等关系改写为塔心坐标关系 |

建筑卡中的报告尺寸沿用既有尺度记录及其“约”“残存”等限定，不据此在主图生成矩形足迹。寺院墙线仍为部分遗存，不能与301×212米的表列数字拼成完整院墙；塔基尺度不等于整座寺院范围。C03不定位到新的文献实体；C04也不因共享寺院ID而把寺院全部关系压到塔基点上。

## 三个场景与五类功能

场景数据直接读取`research/prosperity-v4/street-clusters-p453.json`，保留原节点、关系ID、原文、A／C等级、适用范围和限制，不另写一套历史判断。

| 场景 | 对象／关系／事件 | 共同视图中的用途 |
| --- | --- | --- |
| K01 宫前 | 8／8／0 | 永宁寺、两卫府、司徒、国子学与太尉的相对关系；唯一C层为K01E08太尉道西解释 |
| K02 建春 | 6／5／2 | 第一石桥、东石桥及桥北大道两里的关系；527年事件只归第一石桥 |
| K03 洛南 | 6／4／0 | 宣阳门、永桥、古洛水、四通市、鱼鳖市与归正里；六个节点均无来源图地理绑定 |

五类功能原样复用`road-functions-p452.json`的T01寺院、T02官署学校、T03道路桥梁、T04市场、T05里坊。分类涉及15个不同对象；`ic_palace_avenue`、`ic_changhe_palace`、`road_eaststone_north`、`gate_xuanyang`、`luoshui`五项作为场景参照保留，不强加功能类别。功能筛选不生成用地色块、院墙、人口密度或店铺数。

P452的R01—R05是已有情境概括，与P453逐条关系存在内容重叠，不能再加为五条独立史实。P452 R05的整组C层也不覆盖P453逐条等级：K01中只有K01E08为C，其余七条保留A。A级表示原文直接关系，不表示地理测量精度。

继续保留以下身份与推断边界：宫前御道与来源图铜驼路不强合；建春第一石桥、东石桥和永桥分别保存；四通市与永桥市为主名／俗称，鱼鳖市为另一条归正里巷市记录；国子学在司徒府南不自动成为独立明文“御道东”；太尉在永宁寺东不自动推出御道东；“一里”“四里”不换算成GIS路线。K03不把现代洛水线或学者图上的桥符端点当作北魏桥头。

## 来源链与下载

`tools/city_common_470_relations.py`的`build_relations(root)`逐条复用P453，解析P1文字校读、B1决定及B7洛南记录，并提供各自原记录、定位和出处链接。P453、P452、P1、B1、B7五份直接输入均附SHA256。B7的LR01、LR07、LR10按原`quote_locator`和`sources`读取；不同电子整理本不当作独立考古测量。

新页面为`prosperity-city-common.html`，本批资源集中于`common-470/`，交付独立SVG、JSON、CSV及离线ZIP。**本批不生成新PDF。** P469的两幅来源骨架SVG及两页PDF继续保留原发布字节和入口；旧PDF不改名包装成本批新图册。P451建筑卡、P452功能分组、P453关系与P469水系原数据不因共同视图而重写。

本批城市17条关系与P469的100条水系记录、34项水系旧编号分别统计。共同阅读入口不是新的水力连接、古河线或地理点，不能以同名参照相连为由将不同层位或时期的水道合并。

## 验收及后续断点

验收应直接对照原JSON与几何，核查25项选择范围、24／1默认显示、4张建筑卡、K01—K03原记录、C03空身份与C04墙线绑定、15个功能对象和5个参照对象，并在桌面、手机、无脚本、深链接与实际下载中核对。P469旧SVG／PDF字节、首页H2和旧数据须继续通过保留检查。

正式交付仍以AGENTS规定的PR审查、主分支`build → deploy → verify-live`和正式站资源回读为准。最终SHA、运行链接、检查报告、截图及尚未解决项登记到[固定交接表 #52](https://github.com/mechgouki/luoyang-city/issues/52)。这里不预写尚未发生的成功次数或“已完成上线”。

2022年运河报告继续按用户要求暂缓。已知来源足以推进共同视图，不反复以缺书或目录检索阻塞全部工作。下一阶段根据真实新增的测线、分期和共同控制依据扩充可定位内容；在证据出现前，不从关系板、建筑尺寸或已批准全景反算古址。新增古代地理坐标、现场共同控制点、院界、道路补线、古河岸及上部建筑高度均为0。
