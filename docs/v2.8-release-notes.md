# v2.8 研究整合地图 / 网站 0.5.0

## 本次针对用户实际看到的问题
默认地图页主标仍写“交互图册 v2.4”，最新研究仅附一条链接，容易使网站看似没有更新。v2.5—v2.7实际是独立专题，几何母图没有随之变成新测绘。本版修复可见入口、整合阅读和发布资源一致性，不以更换版本号冒充新的历史定位。

## 具体交付
- 默认页、品牌、页标题均显示整合版v2.8；静态HTML本身即包含新首页，而非等脚本替换旧版标题。
- 独立`master-v28-review.svg`在35组原图符上加入专题覆盖，原有几何子树经逐项比对不变；339个实体的研究对应可下载。非定位群组不新增点位。
- 地图可切换最新研究、事件阅读、仅底图；年份为516/527/534/546/547。事件表示记载范围，不推导持续毁坏；城市总括与无单独锚点的可移动物不分配坐标。
- 点选地图直接进入整合证据、空间方案、水陆段落和事件，而不要求先知道专题入口。
- 单独`v2.8.html`入口、地图SVG与发布说明。旧37页明确为v2.4底图档案。
- 所有执行脚本、样式和读取的研究JSON/主地图采用内容指纹URL；当前页通过无缓存请求核对release.json的提交。发现新提交给出本站更新入口，核对失败不声称已更新。
- 不能远程消除任意外部缓存中仍保存的旧HTML；独立版本入口提供避开旧首页缓存的直接路径。本地验收受导航策略限制时，以CI和正式站HTTP及浏览器实测为准。

## 发布完成条件
旧三套浏览器检查不删减，新增默认首页、叠层、真实点选、事件作用范围、版本入口刷新、旧未版本化资源缓存模拟和手机操作测试。PR通过后合并，main的build/deploy/verify-live及v2.8浏览器检查全部通过再关闭Issue #7。
