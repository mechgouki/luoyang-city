主图取景呈现宫城、宫门、长街、寺塔、周边街区、水系与远山的宏伟尺度，但这些元素 **是研究启发的艺术组合**，不能证明真实城市东南角河岸、桥位、塔楼相对宫城的精确坐标，更不能从像素画面反算北魏古地面高度或真实人口密度。
