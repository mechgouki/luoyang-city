# P5 北魏洛阳城市骨架：河湖与主干道优先查证（研究基线）

2026-11-18 用户明确要求：**停止继续增加建筑细部，优先把全部重要河流、湖池与主干道核准**。这份资料是在P1–P4.5.3已发布遗址点/八项道路残段基础上的新研究整理，不声称已经给出了全部古代经纬度。北魏复原的目标时窗仍为516—528年综合场景。

## 直接结论与证据缺口

- 现有P1来源图30个概略地理图形，**只有1项明确的水线是现代1997年航摄/1999年测图中的洛水参考线**（`geo-modern-luo-river`），不是北魏洛水。没有任何已审核可配准到516—528年的连续古洛水、伊水、阳渠、谷水或任一宫苑湖岸。申遗汇编显示西壕/东壕局部钻探，但既没有完整带尺古代壕岸，也没有统一地层年代、测孔坐标与原始高度控制。
- 原P1的8组道路只是在申遗来源图上概略绘出的遗存多段线；《文化瀍河》内城勘探综述却列**东西5条、南北5条**，中国社会科学网专题另述**外郭城9条大道**，旧8线没有完成与主街5+5及外郭9的一对一复核。这里三套数字**是不同对象和调查尺度**，不得叠加成全城27条已测大街。
- 2024白马寺附近北魏里坊局部发掘新见**6条里坊道路**，区内道路间距东西横道为40m、南北纵道为86m；**这两数是路与路之间的间距，不是道路自身宽度**。2025原报告又记南坊门/内部十字街与西阳门外大道连接。但这只是该局部遗址，不能复制到全外郭坊格。
- 水系按河流、引水/千金堨、城壕、城东分洪与渠、宫苑池苑分类。2026黄学超论文重新解释北魏引谷/瀍和湖沟、千金堨、洛水枝渎、建春门外阳渠及鸿池陂的多朝代更迭；**解释层不等于已测GIS**。尤其文中认为建春门外御道北侧勘出的较宽水道可能属**东汉旧阳渠**，而北魏的阳渠沿**道南**东去。这是研究者依据文本、历史渠线和勘探解释提出的时相判断，在未核原始断代测线前不能作为硬地图定论。
- 2024尹玲玲、罗丽娟地质研究摘要指出洛河在汉魏隋唐阶段持续北迁、伊水东延南移、伊洛汇合位置持续东移，与申遗文本“后世洛水北移、毁内城南墙”在方向上有可比之处，但没有一份本项目能直接量读以画出516—528年古河槽的独立带坐标古河道图。
- 2022千秋门区域发掘公布的三条魏晋时期石渠，以及汉代、北魏另一期水道，是**真正的局部考古发现**，但原带尺测图及北魏通水连续性的核定仍缺，不能在P5图里画三条贯穿宫城的北魏水线。

## 水系分类目录

基础自然河流为古洛、伊、谷（涧）与瀍。城西重构关注湖沟旧渠／千金堨与千金渠／可能引洛枝渎／张方沟；城区关注多朝代护城壕与建春门外阳渠；城东关注阳渠及东南谷水分洪支路与鸿池陂；宫城关注千秋门多期暗渠和华林/西游园诸池的地下石窦集合。上述共15项水体/水工系统记录，每项`ancient_516_528_metric_geometry=null`；其中考古已有局部点段，但**未取得项目可用的整线注册控制**。

现有用户历史对象中11个具有明确独立旧ID的湖/池：
濛汜池、碧海曲池、昭仪寺池、永和里北池、永和里南池、翟泉/苍龙海、天渊池、玄武池、流觞池、扶桑海、咸池。其余还需另列景明寺三池（**文本数量，非三个已定位点**）、土山鱼池、城东南池与方湖，以及鸿池陂。翟泉与昭仪池不是同一池；濛汜池夏有水冬竭；永和里南北池为两处；古籍“凡此诸海”系集合概述，不能直接生成每两湖之间相连的地下河道。

## 内城与外郭主道：分开统计与分期

1. P1来源地理：8项旧绘残段（Lz-3铜驼、Lh-2宫南横街、3横道、3纵道），现有表现位置为历史遗址来源图概化，**不是完整交通线路**。
2. 2023《文化瀍河》内城主道综述：东西5、南北5，附有门名配对及道路序列。其“汉代雍门内大道”本身含前代分期，一些“开阳门—建春门”命名的南北/东西分类还须核原测图与地理方向，**不能按文字两端自动拉一条直线**。
3. 2024中国社会科学网综述：1980年代起勘查北魏外郭城9条大道。**本项目没有每一大道可独立验证与旧P1相接的全套原图**，不能一次补九根线。
4. 2024—25白马寺局部里坊十字街与西阳门外大路，属于不同尺度的局部街网，不能以40/86m街间距代替全城主道路宽。
5. 2026文章讨论建春门东至东郭的街道宽**约15–20m**及南/北相邻渠道的不同期段，应核文中引用的原始考古勘查图及坐标后再进入历史GIS。
6. `road_jianchun`、`ic_palace_avenue`、`road_eaststone_north`、`road_xuanyang`、`road_siyi`等原本为不同文献区段与道路实体ID，不能用名称相同或纵横方向相近就合并为一条测量道路。
