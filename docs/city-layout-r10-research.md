# R10.1：全城总平面与十一片区布局深化的研究依据

研究基线：`1a988bc51adc74288ec8a8aa682499444007a33c`。目标为516—528年的盛时综合研究窗口，不是声称某一天所有遗址、建筑和水路同时处于同一状态。本轮沿用339个原实体ID、84条道路证据记录和34项水系索引；首页V12与V13二修栅格图不改，2022运河报告继续暂缓，毁后场景后置。

本轮把十一片区都展开为可读、可回查的布局关系：**42个独立图窗，96项“空间判断—依据—图面变化”决策，23项片区证据缺口**。新增表达来自既有材料的系统复核与制图，不是新增考古发现。数据详见[片区关系与决策](../research/city-layout-r10/regions.json)和[来源复核与指纹](../research/city-layout-r10/source-review.json)。

## 1. 这次完成的图面层次

全城入口把原有来源图位置、文献相对关系、独立考古窗口与尚待定位的记录接入同一阅读系统。每个片区的图窗仍独立排版：它们没有共同古代坐标系，窗口间距和图签大小也不是古代距离或建筑规模。只有明确标出的方向、所属、事件次序或条件关系构成判断；未连线对象之间不据排版推导新方位。

42个图窗中的321个节点是**图签出现次数**，含重复参照、构件、来源道路、量测对象及未知接口。去重后，245个既有实体在图内得到表达；11个对象继续在分区对照名录说明，83个保留在待分区工作名录。339项完整登记，不等于339处建筑足迹都已绘定。“待分区”也不是说原典完全没有地点信息：其中包含远郊、异名互见、历史层以及尚未进入这批关系窗的对象，不能称为83处已证失踪遗址。

本轮实际图形有259条关系边。这一数字包含方位、成员、同段记述、候选同体及事件次序；例如一条“东北”判断可拆成南北轴与东西轴两个分量，它仍只是一条原始判断，不能计为两次独立发现。关系边和图签均能关联本区相关的决策，避免点击退回页顶而找不到具体依据。

图册采用16页编排：全城总图与图例各一页；R02、R03、R10各分上下两页，其余八区各一页。页数服务于可读性，没有为了压在固定页数中而删去已经能够成立的关键关系。实际SVG、PDF、网页、手机及下载验收由构建和发布流程另行记录；本研究说明不提前替代这些检查。

## 3. R9四个关键考古节点全部接入

四组节点保留[既有R9的20项决策](../research/city-spatial-r9/decisions.json)，分别接入本轮R07、R02、R03、R04。它们既在决策表出现，也在图窗中成为实际对象和关系。

### 宫前—永宁：SP01—SP05 → R07

门符、寺墙与道路残段分别按原对象处理。寺在宫门南、御道西，四邻又各以寺为参照；太尉“寺东”不能改写成“道路东”。两卫的直接路侧与后续官署的段落继承分层。R01来源三段路迹与T01文献御道只作宫前地段候选联读，未把南端补到宣阳门或永桥。夹路支水保留分支语义和未知接口，不画成道路中轴的一条长沟。

### 白马坊街：SP06—SP10 → R02

考古坊街使用独立关系框，节点没有绑定为文献白马寺实体。道南“西阳门外三里”的文献白马仍在另一窗保留原路参照；两组不作同体或共同坐标配准。

中央纵横街的十字关系明确，四条次级街分别表达；没有补成九个全部被发掘确认的交点。X02/G11约束O02北缘的局部接触，但到中央十字的连续揭露和长度仍为空。22米归居中纵街，7.5米归北缘缺口，4.6米归车辙密集带；可能门槛槽的另一4.6米量测另论。86米、40米是报道街间距，量距基准未核，不能倍加成172×80米完整坊地。槽与基础支持门址解释，不是水渠或完整门楼，咸池W25只作同大道地望索引。详细来源见[R7白马核验](../research/city-nodes-r7/reviews/baima.json)。

### 司马门—宫院—仓区：SP11—SP15 → R03

宫院东墙、P01主路与宫内仓区有可靠三带次序。约40米是最宽路面，P07约4.7米属于宫院内部夹道，P08约13米属于仓区内路，三数不合成同一断面。仓区内路分窖区东西，分隔墙区分北部建筑与南部窖穴；未把墙路交点补为完整十字。宫内外仓储来源和168口、三排、已发掘13口等统计范围未核同，不转为地上屋顶阵列。独立图框的路迹、范围框及参照门身份分别保存。

### 建春—城东水路：SP16—SP20 → R04

第一石桥、东石桥、七里桥分组，东石桥南北通行与桥北两里路侧可读。七里桥到三门的一里另起，不从桥名倒算建春门至桥七里。527颓桥仅承第一桥，修复状态未明。路北宽渠调查记录、北魏路南阳渠的研究解释、汉晋门下暗渠和七里涧两种文序解释各自独立，不合成同期双渠、鸿池出口或桥头古岸。

## 4. 现有图纸继续有效，欠缺的是接合条件

本轮没有把既有局部平面或尺度图说成“尚未绘制”。P2已完成阊阖门基44.5×24.4米、太极殿遗址约100×60米、永宁寺塔基地上遗存38.2×38.2米三张定尺参考片。它们量测对象不同，参考矩形也不等于完整屋顶、柱网或整组院墙。见[P2尺度依据](../research/prosperity-v2/core-scale-basis.json)，尤其`/templates`与`/coordinate_reference`。

P3已把阊阖门原生555×434像素局部平面转为图内米制关系，登记10个可辨构件。图中20米比例尺和北箭可以支持局部读图，但独立地面控制点仍为0，不能仅用图内北箭解决与城市基准的平移和旋转。见[P3局部门址平面](../research/prosperity-v3/gate-plan.json)，尤其`/source_raster`、`/calibration`和`/components`。

既有宫城中轴、分段量距、太极殿与东堂北侧宫院、宫城边界仓区、建筑尺度结构等专题也继续保留，并由全城页面按区域联通。R10绘制的是这些不同层次之间能够成立的阅读关系；它没有把既有局部图的独立坐标强行拼为共同测量。太极宫院310／370／380米等报道异记仍按测量对象和版本比较。2017年东、北边界与东北角已有发现报道；欠缺的是完整原图及共同控制，不能再写成“边界尚未发现”。见[P4.3边界复核](../research/prosperity-v4/palace-boundary-variants-p43.json)。

现代地形图同样已经存在。尚不足的是可归入516—528的古地面高程、池岸与河岸层位，不是“还没有任何地形图”。现代DSM、来源图遗址范围、古代时层和项目布局假设继续分别保存；不以现代低点认定古池，不以现代山峰定位宫苑人工山景。相关方法见[历史基准研究](historical-datum-b5-research.md)与[地面核验研究](ground-review-b6-research.md)。

## 5. 当前采用的校读与更正

本轮采用B8、P468的当前更正，旧版JSON、PDF与ID不覆盖。

- **B2 G15旧引文层**：旧`quote`为压缩概述，不能再当逐字古文。B8保存了准确正文及“陽穀”原字、改“渠”校注的层次。本轮未暗改旧JSON。见[B8 CB14](../research/dual-b8/cross-batch-review.json)的`/records/13`。
