## 本轮图像与空间审查

V16 使用原 V12 整景作为底层、V6 立面作为塔形参考。图像生成工具只编辑寺院局部；采用的第4次局部图通过项目原有的可编辑 SVG 场景装配流程，放回原画的 `x=380, y=180, width=270, height=270` 矩形。整景生成的第1—3次及后续第5次合成试绘均未采用。SVG 只放置原景与生成局部两张栅格图，没有绘制矢量立面塔，也没有再次生成全城背景。

矩形内侧四边使用2px渐隐掩膜处理树冠和地面接缝，范围不向矩形外扩大，也不模糊塔身。原景、采用局部、装配参数、SVG、渲染程序、源 PNG、实际提示词、审查说明及两幅网页 WebP 均有指纹。运行 `node research/homepage-yongning-v16-20261128/render_scene.mjs` 可按保存的参数重现 SVG 和网页图片。

发布前须对同一张最终图完成六项空间审查：相机与地平线、台基落地、庭院与邻楼关系、远近尺度、屋顶坡面透视、光照与空气层次。审查结论绑定实际生成 PNG 的指纹；缺少图像或未通过任何一项时，发布器会拒绝构建当前版本。

图像记录中的 `approved` 仅指在用户修改指令下通过实施审查；`approval_scope` 与 `user_final_pixels_approved=false` 明确表示没有冒充用户对最终像素的单独批准。图像审查详情见 `research/homepage-yongning-v16-20261128/visual-review.md`。

- 原图空间环境的保持包括画面关系与透视审查。源 `source-scene.png` 在编辑矩形外的1,500,452个像素经解码 RGB 比较全部与 V12 相同，最大通道差为0。该精确结论仅适用于源 PNG 的指定区域外；有损 WebP 不继承逐像素不变声明，矩形内的背景也不冒充原图逐像素保留。
