# 盛时P4：宫城中轴分段量距、道路、时相与主殿尺度

**本批性质**：对已发表的联合考古资料建立可复算的量距与基址尺比，并制作三个分开的尺度图。它不是以一致控制点完成的遗址坐标配准，更不是某一年的完整宫城复原。项目仍采用516—528年盛时综合层。

## 新取得的来源及实际核读

1. 钱国祥，2012年《汉魏洛阳故城北魏宫城中枢区南部的合作勘察》；奈文研60周年中日媒介的公开会议论文集**中文正文第28—30页**。在线：https://www.kuba.co.jp/nabunken1020/img/nabunken20121020.pdf 。重点核读二号宫门台基、道路、车辙，三号宫门早中晚三期与西南角墙界。钱国祥的日文译稿、其他作者对这批发掘的概述都与原始考古工作有继承关系，不当成另一份独立测量。
2. 奈良文化财研究所2013《纪要》，今井晃樹《漢魏洛陽城—北魏宮城西南隅の調査成果》，**第52页图69**（PDF文件首页）。https://repository.nabunken.go.jp/dspace/bitstream/11177/6157/1/BA67898227_2013_052_053.pdf#page=1 。图是带宫城边界、主要建筑标注和图内200米标尺的正式出版平面示意图；由于缺少与站内共同测量点，不能从现有图片像素提取精确古代坐标。该图另标“一号门”，是否对应阊阖门编号或单独设施须查原正式简报。
3. 徐龙国《两汉魏晋南北朝都城建筑的发展演变》，《中原文物》2020年第3期，**第59页图三与相关文字**。https://hrczh.cass.cn/sxqy/kgx/202502/W020250228392257504164.pdf 。报告太极殿主殿北宽102.3m、南宽98.4m、进深约59—61.5m；太极东堂48×23m，距主殿东侧约14m，三殿东西并列。非完整建筑上部结构证据；西堂缺本批独立尺度。
4. 洛阳市考古研究院2024-03-08《汉魏洛阳城宫城太极殿遗址》，https://lykgyjy.museumcloud.com.cn/xueshu/739.html ，报告太极殿遗址至阊阖门约460米。
5. 河南省文物考古研究院公布2017年度发掘总结，https://www.hnswwkgyjy.cn/NewsView.php?News_ID=583 ，报告太极殿宫院东北角院落东西96m、南北残27m和4.7m夹道，不能扩大为整座宫院边界。

## 核心新结果：数字能限制什么

| 研究对象 | 报告数值或结构 | 使用约束 |
|---|---|---|
| 阊阖门→二号门 | 约95m | 未核测线端点，不能分配精确坐标 |
| 二号门→三号门 | 约80m | 同上 |
| 三号门→太极殿 | 约300m | 同上；未确认指台基哪一边 |
| 三段相加 | 475m | 计算结果，不是直接实测总距 |
| 阊阖门→太极殿另一报道 | 约460m | 相差15m，但不确定端点及取整；不能断言原始史料互斥 |
| 二号门基 | 东西约44.5m、南北约24m；三门道；无双阙 | 附属建筑约16m南北进深，勿从画面套阊阖门双阙 |
| 二号门道路 | 两条东西路分别距门址南约23m、北约40m，宽约10m；主轴南北包砖路7.9–8.1m；车辙间距约1.2m | 距门未注明从中心还是边缘起量，不能作为城市道路边界 |
| 三号门早期 | 南部残存约40×10m | 北半遭破坏，不能把残存40×10作为当年门址总尺寸 |
| 三号门中期 | 后筑夯土约55×45m，时代北魏晚期或以后 | 其中包含北魏瓦片不构成“北魏516—528建成”的直接证据 |
| 三号门晚期 | 北朝晚期（北周）在早期南部残存处布置柱网，基部约40×10m | 北周形制不能倒推北魏盛时 |
| 太极殿与东堂 | 主殿北边102.3m／南边98.4m、进深59—61.5m；东堂48×23m，报告东侧间隔14m | 宽度南北不同；东堂在图中的南北相对位置仅为显示设置 |
| 太极殿东北局部院 | 东西96m、南北残27m；夹道4.7m | 只为局部院，不能填为完整宫院 |

## 发布图式与证据边界

- `axis-segments.svg` 只按文献分段报告安排四个节点；475m是相加，另放460m对照。不得用该图获取真实坐标或测距误差。
- `third-gate-phases.svg` 三图并排、同尺度但**没有空间重叠**。残基、后筑夯土、晚期柱网三时相保持独立。
- `taiji-dimensions.svg` 同尺度只表达已见主殿及东堂尺寸，主殿保留102.3/98.4m两宽。西堂只标存在，不给未经核的宽度；图面选择的Y位置不能当作证据。
- `data.json` 及`measurements.csv` 保留原始报告数值、近似状态、来源ID、时层和未解控制点。原刊PDF通过链接供直接阅读，未未经授权重新打包。
- 新专题可从首页及P3阊阖门专题进入，旧P1—P3图件和数据保留。合入主分支且GitHub Actions `build→deploy→verify-live` 全部通过后才称已上线。

## 接续优先级

1. 针对2013原刊图69的“一号门”与阊阖门标注重新审查分期、研究编号，避免遗漏或重复计数。
2. 查《考古》2009年第5期二号建筑、2010年第6期三号建筑两篇发掘简报的**原始可标比例平面**，区分重绘图与调查基址，把新的读线保留在各自图内局部米制。
3. 查太极殿和东西堂的发掘原版分期图，尤其是被后期破坏的三号门北半部，确认可用于北魏盛时的范围。
4. 把查明的独立共同控制点、朝向基准和古地面证据接到P3的位置模型。共同控制零的状态未变化之前，绝不把三座门的局部图强行叠成全球坐标上的完整院落。
