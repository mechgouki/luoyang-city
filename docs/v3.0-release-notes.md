# v3.0 第一批：真实现代地形基底 / 网站0.7.0

## 本批目的
直接处理已取得的Copernicus GLO-30 N34E112真实栅格，而非继续制作占位图。现代地表、近现代扫描地图和古代文本网络分别显示；不把DSM视为北魏裸地，不从旧示意图反推经纬度。

## 输入和处理
原栅格及两幅AMS扫描图以固定URL和SHA-256核对。保留原角度网格样本，双线性重采样至EPSG:32649的30米工作网格，再以WGS84窗口112.35–112.95E、34.50–34.95N的像元中心掩膜裁切。该窗口是分析范围，不是古城边界。EGM2008源高程未作垂直转换。网格间距不代表水平或历史定位精度。

产物包含原尺度DSM、显示用90米标准差高斯平滑DSM、两种坡度、多方向山影、25米等高线GeoJSON、完整处理参数及GIS下载包。山影采用225/270/315/360度等权照明、太阳高度45度、无高程夸张。平滑用于显示，不是移除建筑或植被；无填洼、无古河道自动提取。

## 图幅实际核查
NI49-7 LO-YANG的东界为112度30分，不能独自覆盖分析窗口。沿用此前取得的相邻NI49-8 CHENG-HSIEN补齐原图覆盖。两图为1:250,000、L500、Edition1-AMS，1955编纂；7图1964年11月印刷，8图1964年9月印刷。编纂使用跨年资料，不把印刷年当成地形观测年。图注横轴墨卡托、国际椭球、100米等高距及50米辅助等高线。

已视觉核查真实扫描图边栏，未用OCR。水平大地基准尚未识别，无独立地面检查点；没有把原图叠成已配准WGS84历史河道。现代地形中的112度30分分幅线只是图面经线参照，非古代边界。

## 网页
独立入口v3.0.html提供真实设色山影、灰阶山影、原尺度/平滑坡度、等高线和图幅分界。拖动、缩放、近邻样本读数、来源原图、古代文献分栏和下载可操作。读数使用180米显示采样网格，不冒称30米测点。默认首页明确展示真实地形预览和入口，旧v2.8/v2.9页面与原JSON/母图/PDF保留。

## 历史研究边界
古代网络继承v2.7的48节点、42关系、20段证据；新增古代地理定位为0。图符、渠线和建筑尚未配准。当前完成的是现代地形处理和图源核查，不是完整的北魏地形复原或真实水文模拟。史料结果与地形计算结果不混计。

## 可重复执行
安装工作流中固定的rasterio/numpy/scipy/pyproj/Pillow/contourpy版本。先执行v2.9构建链，再运行：

```sh
python -m unittest discover -s tests -p test_v30.py -v
python tools/terrain_v30.py
python tests/browser_v30.py
```

已有原始文件可放入`.cache-terrain-v30`（cop30.tif、ams-ni49-7.jpg、ams-ni49-8.jpg），通过固定哈希后不再下载。程序支持`--no-download`，无合成栅格回退。合成平面仅用于单元测试。
