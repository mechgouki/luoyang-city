# P4.6 北魏洛阳城市骨架优先：河湖水网与大主干道证据锚定首轮

**研究阶段**：北魏洛阳516—528年盛时综合层。  
**用户新优先级**：不再先扩建非核心建筑，优先处理“所有河流和湖的位置、所有大主干道的位置”。**目标是证据分级、完成能够被核实的部分，公开其余缺口，而不是以艺术图补齐。**

## 总体结论：两项都尚不能宣布“全部确定”

既有P1来源地理图有**30项**图示几何，包含**8项**内城道路遗存线，**1项1997/1999近现代洛水**；没有可作为北魏古槽的统一经纬线、已量读完整湖岸的地理多边形或全外郭城市干道路网。旧P4.5.2所述8项道路残段**与**研究中发现的外郭九条御道不属于同一统计口径，也可能部分描述同一空间的不同环节，**不能把8+9+其它硬凑为21条完全不同主干道**。

本轮首查登记 **34项河流、湖池、水工/渠道**，**21条来源道路记录（8项内城旧图、9条外郭勘探汇总、2条补充南外门道路、新考古2项）**，这些数字只表示**已登记证据项**，不是北魏某时刻真实水道或道路条数。加入水利研究的新来源，并不改变此前封存的任何已有地理坐标。

## A. 水文：河谷、工程渠系、苑池按时期和证据分别整理

**A1. 主要古水系**：洛水（古槽未定）、伊水、谷水、瀍水、城周阳渠、千金堨/千金渠、曹魏旧湖沟、北魏引洛入谷候选“洛水枝渎”、张方沟及东西城壕。2026年黄学超的研究依据《水经注》及《洛阳伽蓝记》、既有局部探勘提出谷水北支沿北墙、南支沿西/南墙、东面汇于建春的水网解释，同时明确北魏对千金堨、湖沟故道、洛水枝渎及城东阳渠做过不同工程。*这些是分期水文和历史拓扑解释，未获得全部水道古槽现地坐标。*

**A2. 已有考古**：申遗文本总结西壕局部钻探宽约18–28米，东壕通常约18–40米，并记录局部淤积和埋深。宫城西墙2011剖面有汉晋渠、魏晋墙基及北魏墙基的叠压；2022公布魏晋水利设施。**既不能把局部水道当作全城完整水道，也不能把早期渠系直接当作516–528仍通水。**

**A3. 湖泊不能混同**：《洛阳伽蓝记》记太仓南的**翟泉（苍龙海）**在华林园东；华林园内的“大海”则是另一水体**天渊池**。园中还记玄武池、流觞池、扶桑海；宫城内外另有濛汜池（夏有水、冬涸）、碧海曲池、昭仪寺池、永和里南北两池、西郭咸池/土山鱼池、景明寺三池等。文字提供相对方位/名称/季节性/地下石窦连通，但没有真实边岸像素和古代绝对坐标。**本项目禁止将翟泉和天渊池画成一湖，禁止画一个固定面积的常年濛汜池。**

**A4. 现代洛水与古河道不同**：既有2012申遗保护图采用1997航摄、1999测量底图，在P1形成 `geo-modern-luo-river` **单条近现代河道概略线**；申遗文本又说明历史洛水发生过北移及南墙水毁，但不能仅据方向叙述反推所有北魏河槽，不能使用现代DSM低洼处自动画湖。

## B. 城市主干道：新证据大于旧8条P1记录，先核原测线

- **B1. 已有内城底图**：P1图06a的8项遗址路迹（Lz-1/2/3/4，Lh-1/2/3/4）只可按原矢量多折线分段呈现。铜驼大道Lz-3表中现存段长约1650米、宽40–65米；该尺度未独立验证能代表北魏每一朝所有路段。宫南横街Lh-2仅有来源图T形与铜驼街关系。
- **B2. 外郭主干线**：地方史综述称勘测/发掘有9条延续内城城门的御道：西明、西阳、阊阖（城西）、承明、大夏、广莫、建春、东阳、青阳门外大道；另列开阳门、平昌门外2条。**这些大道尚需逐条取得原测图、坐标、路宽与分期**，现阶段属于“有考古勘探汇总，但本站尚没有统一可配准线路”的档。
- **B3. 2020新发掘**：新华社引中国社会科学院洛阳汉魏城队的多点探挖称西明门—青阳门东西大道约长2.5公里、宽34米，车辙及路土延续至北魏，并与铜驼街交叉。它与P1 `Lh-1`南部横道可能有关联，但**原刊逐段端点及共同标尺未得到前不得写同一条精确线**。
- **B4. 2025新发掘**：2026年《人民日报》报道白马寺北魏里坊发掘西阳门外大道与南北向居中坊内道路交会，见车辙及约7.5米坊门口。**7.5米是坊门缺口解释，不是西阳门外大道宽度**。

## 与同期P5来源草案的互补核对（避免重复或错误合并）

仓库另有正在讨论的PR #46（P5城市骨架研究草案），与当前P4.6并行且仍未正式合并。我们已复读其原始数据与论文引文，将有可靠出处的独立发现并入本项目P4.6来源登记，并在新字段中保留其完整证据口径；**未合并其有误的CI产物或以同名大道自动覆盖主分支**。

- 2023年地方考古综述另有内城**东西五大道／南北五大道**，其中汉代雍门内道可能跨早期时相。该目录不是P1**8项**同一尺度且已配准的遗存路段；不能把两套数目求和或作一对一编号。新增`inner_city_ten_road_literature_summary`保留十条文献路线的逐个状态与原刊缺口，GIS polyline均为null。
- 2024白马寺里坊新见**六条局部道路**（三纵三横），研究者报告横街间距约40m、纵街间距约86m；两数是**相邻道路的间距**而非道路宽、坊门宽或全城街坊统一尺度。当地2024报道还指出南北居中十字街相对更宽，此不应自动外推整个北魏外郭城。新增`baima_local_ward_2024`明确禁止全城复制。
- 2024尹玲玲、罗丽娟地质研究提出洛河北移、伊水东南伸展和伊洛合流位置改变的长期趋势。但缺针对516—528古槽的可配准平面和统一时间地层，因此`ancient_luo_yi_geologic_trend_2024`记录为不可直接上图的历史地貌趋势。
- 黄学超2026水利论文还对建春门大道北侧较宽古渠的**东汉/北魏分期**提出解释：道北较宽渠有可能为汉代旧水道，而北魏阳渠在道南。此为学术分期推断，`northern_wei_east_yangqu_phase_controversy`明确禁止两条渠未经分期就自动拼成北魏全段主水道。
- `original_document_acquisition_queue`逐项登记缺失的7份重要原始带尺测绘及勘探报告，尤其1993外郭九大道及水道勘查、2011阳渠鸿池陂、2016漕运考古、2024河槽地质图、2026水利图1/2/4和白马寺2024–25原图。各项标记`scaled_survey_plan_acquired=false`；这是下一阶段**能否真正把城骨架锚定到地理空间**的进入门槛。

同期研究草案是一个有价值的独立工作分支，后续需进行PR级统一审阅，避免形成两个同名而不相容的“最终北魏地图”。当前P4.6是**第一轮证据总账**，而非声称已经把所有河湖与路网校正完毕。

## 当前画面与数据结构

新数据 `research/prosperity-v4/hydro-roads-anchor-p46.json` 登记34项河湖水工、21项**未去重**的道路来源记录及各项独立来源；其`position_tier`分为：近现代来源图位置、旧遗址来源图线、有考古但未取得共同坐标、历史水文拓扑推演、古文献相对方位、分期条件解释。任何“待核”都不是直接否定其历史存在。

网站 `prosperity-hydro-roads.html` 和四页研究图册包含：古水网络与苑池关系**非地理**示意、内/外郭主干道证据分层、完成度/测量控制门槛板，以及旧P1来源图**逐字节不变副本**。页面可按中文名、来源与状态筛选原始水体和道路目录，另有CSV/JSON/PDF/ZIP。

为保持用户批准的主页Hero版本，**只从上一步P4.5.3专题新增一个链接**；旧研究、原来源图和H2艺术全景均不更改。

## P4.6 完整锚定的硬门槛（仍未全部满足）

1. 对所有主要水道分别取得**原始带尺河渠考古平面/钻孔剖面/河道年代/高程基准及复测控制点**，验证北魏516–528时段是否通水，以及方位、起讫与分支。
2. 对翟泉、天渊池及大园池，确认究竟可以达到哪一级：遗址实际轮廓、文字可限区域，还是只知所属园内。**有文献名不等于能画准确湖面**。
3. 对九条外郭御道及两条南外路，查找同一原刊带尺总图和分段探沟位置，建立可比的宫城/内外郭城门—道路交叉空间控制。
4. 对2020东西干道与2025白马寺里坊新考古，补发掘测绘图、分期和测量端点，再决定与原P1 `Lh-1`、西阳门外御道对应的准确道路片段。
5. 河桥、河门、官署与大道的共同空间控制确定后，才能做有物理意义的交叉口/桥宽/河道宽度/可导航道路连通模型；否则维持非地理关系板。
6. 本轮源审查不替代野外实测与原报告。阶段完成只代表**锚定证据底稿上线**，不等于北魏所有河流、湖泊和主干道已经完全准确定位。
