## 为什么修订

V15的技术门禁曾全部通过，但用户随后明确否定其空间表现。先前的塔形过于接近立面表达，屋檐透视、侧面、基脚与周边庭院的接合未服从原来的鸟瞰场景。因此，本次把V15记为“技术验收通过、视觉被用户否定”，保存原证据，不把技术通过改写为用户认可。

## 实际修改

以原获准V12全景作为背景，重新生成永宁寺的高分辨率局部，再由项目原生SVG装配回原图。新的塔身具有可辨识的九个完整层段与九道主檐，并按原图校正俯视面、侧面、收分和屋顶走向；塔脚回到原庭院位置，保留门—塔—后殿的前后轴线、门后院落及后殿两翼。光照、投影和材质色调同时与周围建筑衔接。

局部编辑范围为原1672×941图像上的`x=380, y=180, width=270, height=270`，内缘羽化2px。局部之外共1,500,452个像素，在无损`source-scene.png`与解码后的V12 RGB之间逐像素相同，最大差值0。此精确像素保证不延伸到有损WebP。没有用新的矢量塔形替换生成塔体，没有用整幅重生成移动原城市布局。

五次图像生成尝试完整登记：第4次局部图用于交付，其他尝试因层数或空间漂移未采用。专题原有V6立面、正文、四章、参数和下载保持原身份。
