### 原图到位后的量测顺序

1. 记录版本、印本页与数字页、图号、完整图边和来源；先把剖线方向及全部钻孔编号逐项对回平面图。
2. 分别核水平与垂直比例尺、单位、标高基准及剖面是否存在垂直夸张。原图没有可读标尺时，只记录可辨识的相对关系。
3. 按每条剖线记录渠宽定义、渠底及两侧界面、渠深、各淤积界面和读图误差。渠顶宽、渠底宽、残存宽不可混用。
4. 将地层、出土物和报告断代原文逐项关联到测点或岸段，判断哪些证据可以支持516—528年；保留“沿用期未证”等状态。
5. 最后检验这些岸段能否约束永桥桥头。文献四里只作为文献距离条件；没有共同定位依据时，不拼出精确桥头坐标。

继续沿用：引洛渠在津阳门外大街东侧；《洛阳伽蓝记》记永桥在宣阳门外四里、跨洛水；残长180米引水干道属于辟雍，516—528年通水仍待证。出处与分期见[P4.6.6验收记录](https://github.com/mechgouki/luoyang-city/issues/47#issuecomment-6999731106)。
