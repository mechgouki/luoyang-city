## 1. 审阅对象和独立方法

输入为仓库中的 `design-parameters.json`、`calculate_mechanics.py` 和 `mechanics-results.json`。本次未使用作者 `spring_matrix()` 或 `lateral()` 的计算结果作独立求解输入；重力、风力、截面惯性矩、几何软化、层间位移和固有周期均由声明参数重建。

独立式：

- 各层木构合成重力：`w_i = q_floor × b_i² + q_roof × 1.10 × [(b_i+8.8)² − b_(i+1)²]`，顶层扣除项为零；附加塔刹重力仅加到末节点。
- 各层弹性刚度：`k_el,i = η N E d_i⁴ / h_i³`，其中 `d_i=d_0 b_i/b_0`，这是指定等效方柱框架的固定端参考式乘敏感性比例。
- 几何软化：`k_eff,i = k_el,i − P_above,i/h_i`；`D` 把节点位移转换为层间位移，`K=Dᵀdiag(k_eff)D`。
- 独立解 `Ku=f`，并用 `V_i/k_eff,i` 逐层积分交叉核对；质量为 `w_i/g`，用广义特征值重算周期。
- 水平惯性另算 `F_i=CW×w_i(z_i−z_0)/Σ[w_i(z_i−z_0)]`，验证 `ΣF_i=CW`。该荷载没有与风叠加。

最大差异：53 个风／重力工况的有效刚度约 `7.6×10⁻¹⁰ kN/m`、位移 `2.5×10⁻¹⁴ m`、η 阈值 `4.5×10⁻¹⁶`、周期 `8.6×10⁻¹⁴ s`；9 个惯性工况的底弯矩约 `2.4×10⁻¹⁰ kN·m`、位移 `3.2×10⁻¹⁵ m`。这属于浮点舍入。Euler、核心自重、局部悬臂公式也与其声明参数一致。

详细记录及输入 SHA-256 见 `v6-independent-calculation-audit.json`；可复现脚本为 `audit_mechanics_independent.py`。

## 2. 关键数值与限定范围

### 基准荷载

木构合成面积为 5,743.42 m²，屋面假设坡面面积为 6,088.94 m²。`q_floor=6 kN/m²`、`q_roof=4 kN/m²` 时，木架与屋面合计 `W=58.81628 MN`，约 5,995.5 t，不含独立土心，也不是已知完整塔刹总重。

`p=1 kPa` 时，包络实际水平合力为 4.47427 MN；将塔刹按等底弯矩移到屋顶节点后，等效节点合力为 4.476944 MN。各条带质心加载的一阶底弯矩为 278.334 MN·m，全部上移至层顶节点的一阶包络弯矩为 312.016 MN·m。二者区别已经正确记录。

## 3. 已落实的修正与保留的模型边界

1. **位移终点——已落实。** README 已明确位移指 131.8 m 木构屋顶计算点，不是 147 m 宝瓶顶的总摆动。九个自由度最高为 131.8 m，塔刹局部变形仍在模型范围之外。
2. **一阶全局校核与 PΔ 侧移分开——已落实。** 代码、结果与 README 均已明确整体表和示范性柱轴力采用一阶风矩，非真实最不利组合；每个稳定风／重力工况新增 `gravity_secondary_base_moment_kNm` 与 `primary_plus_gravity_base_moment_kNm`。独立逐工况核对 `Σw_i u_i` 与总底矩通过，最大差异小于 10⁻⁷ kN·m。基准 η=.30 的附加量为 32.755 MN·m，总计 344.771 MN·m；η=1.00 和 1.2 m/η=.50 的附加量分别约 9.058、8.727 MN·m。
3. **“负刚度层”为第 1、2 层——已落实。** 结果保存两个失稳层，README 没有只限第一层的表述。
4. **整体恢复矩比值不是基础通过。** p=1 kPa 时一阶偏心 `e=5.305 m` 已大于假定支承宽度 `29.4/6=4.9 m`。条件恢复矩／倾覆矩虽为 2.77，该刚体连续接触假设已越过核心区边界；不能据此声称无起翘。代码 `within_rigid_block_kern=false` 正确。真实柱脚是离散接触，土心与台基如何共同作用仍未定义。
5. **出檐荷载口径统一——已落实。** 局部荷载已改为 `q=4×1.10×(29.4/9)=14.373333 kN/m`，与主表坡面面积系数一致。独立重算根弯矩为 139.133867 kN·m、竖向反力 63.242667 kN；0.3×0.6 m 与 0.4×0.8 m 截面的应力需求分别为 7.729659、3.260950 MPa，端挠度分别为 0.015588、0.004932 m，与结果及 README 一致。
6. **质量保持不变的截面比较——已明确。** README 与结果已说明改 d、N 或 E 而固定合成层重，是单参数刚度敏感性；未补算更多木料增重的组合不是可直接照用的加强设计。
7. **刚度参考不是古建整体上限。** `N×12EI/h³` 是指定等效柱及指定端部约束的参考式。h 是集中节点间距，最上段 18.9 m 跨墙身、斗栱和屋面，不是柱净长。η 统一缩放省略了脚部摇摆、节点滑移、构架剪切、平面扭转和高度变化，因此不能声称对所有历史塔架有已证明的保守性。
8. **独立柱需求也有假设。** `2W/64+M/(16×29.4)` 是选定集中系数、边缘分组和力臂后的需求情景，不是由 124 柱位求出的实际柱力或严格最大包络。Euler 理想弹性值不等于实际承载力；木材强度、缺陷、长时荷载、压弯和接头应力均未给定。
9. **固定质量核心与水平相互作用未建模。** 19.8→10 m、60/80/100 m 土心给出的自重约为 248.4/331.2/414.0 MN；底面平均自压约 0.634/0.845/1.056 MPa。不能仅由这些应力值判断夯土稳定。土心自重不塞给木柱、不给未证实连接的抗侧增益，这两项边界清楚。无核心增益的简化木架失败，也不等于历史永宁寺不可能存在。
10. **手工范围声明不能充当程序验真。** `all_input_historical_unknowns_labelled_as_assumptions=True` 和类似布尔项是作者手工声明，不是程序能自行验证的考古事实。若展示“测试全部通过”，应只称输入形状、代数和数值平衡测试通过。
